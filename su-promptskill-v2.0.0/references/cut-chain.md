# Cut 链

每条源镜建立且只建立一个 Cut，保持来源顺序。Cut 是 Prompt 内部执行单元，不是新镜头，也不能改变源镜内容。

## 机器时间线

机器层保存来源精确时长和累计边界。未知保持未知；小数时长保留原值，禁止四舍五入。

## Prompt 表达

- 全部边界来自用户或可靠来源，且能无损表示为整数秒：允许数字时间段。
- 存在非整数边界：使用有序 Cut/阶段，不写取整时间戳。
- 只有 API 目标时长：使用无数字阶段，不写“总时长”。

Seedance 2.5 最多 `Cut 1` 到 `Cut 10`；Seedance 2.0 与 generic 最多到
`Cut 5`。超限必须重新分组，不能丢镜或合并 Cut。

## 连续性

相邻 Cut 只继承来源已经给出的边界状态、运动趋势、视线、道具和声音状态。不得为了“顺滑”补动作、对白、镜头角度或事件。延长任务的边界状态属于 operation 合同，不代表可以改写原片。
