# 结构化正文与时间表达

标题沿用自有历史范式，表达借鉴用户指定sd25-pe，不宣称是官方逐字强制字段。

| 区块 | 实际内容 |
|---|---|
| 生成目标 | 本组主体、地点与核心过程的一句话，不是全剧摘要 |
| 参考素材职责 | 每个实际采用素材的实体、采用属性及必要排除 |
| 未采用素材 | 本次可访问但不采用的编号；无排除项不写空壳 |
| 主体、关系与场景 | 必要稳定身份、结构和本组当前初态，不抄全场未来台账 |
| 镜头脚本 | 每个Cut对应完整源镜，摄影、动作与实际声音在同一时间过程 |
| 声音与台词 | 按需说明跨Cut声桥、音色和声音关系，不复抄全文 |
| 保持一致 | 真正不变量，不锁死人应发生的位移、转身和交接 |

普通分镜一般保留目标、主体场景、镜头脚本与保持一致；素材和额外声音区按内容出现。纯文字事件可用自然段，不伪造Cut。

## 每组独立但不重演

初态说明“甲持已展开信纸”，而非再展开。当前仍未接物时不使用后文终态。人物身份、房间固定结构稳定继承，姿态、持有与观看对象按本组时点写。不可只说“沿用上一组”。

## Cut里的动态过程

使用Cut 1、Cut 2，原序一源镜一Cut；专业词与观察对象、开始画框、实际路径／焦点变化及结束结果结合。按采用稿的具体程度写，不补来源未定的焦距、路线或表演。源镜可包含连续多动作或等待，不按模板阶段删成一个动词。

对白就地使用`角色（实际声位，已知语言）说：{原文}`，外壳可变、内部字词标点不改。原文真实重复保留；不能做全局字符串去重。音效可用<声音>，音乐可用(音乐说明)，不要把角色括号一律当音乐或把<人物A>混成音效。

画内背身、现场画外、内心、旁白与媒介播放区分；OS不明时回查。讲话时可看听者，来源后置反应不提前。其他人不替说者对口型，但不抹去明确的多人同时发声、笑声、喘气或无声张口。无字幕不删除门牌、信纸文字。

## 三种时间信息

计划镜长留来源与Plan，精确小数不凑整；叙事时间关系在Cut正文表达，如“话音落下后才低头”“接稳后才松手”“声音持续跨入下一Cut”；源稿明确硬时间点继续保留，入口无法表达时局部反馈。

不强制每Cut时间戳。可靠整数预算且确需控制时可写`Cut 1｜0—5秒`；不将小数四舍五入伪装精确链，也不承诺帧级准确。4/8/3秒三镜预算即使请求总长15秒，也不证明模型将精确按此分配。

画幅、总时长、分辨率、帧率与提交状态留现有request／执行说明，构图效果仍写清。原对白中的“16:9”照说，不能当设置误删；原镜时间约束不是可任意删除的元信息。

## 正文干净，核查分层

不加外层标题、代码围栏、来源hash、源镜清单、模型名或优化说明；内部【】是指令结构，不是画面字幕。最终TXT与JSON prompt_text逐字一致，MD／Excel只做载体转义。无依据的“绝对无漂移、最高质量”等包不注入，已采用视觉风格不能借精简删除。

先回来源查漏，再只读正文查新增；源镜超限、动作歧义或缺母版只在正文外说明单元、缺口、影响与所需决定。正常交付不附长篇审计。
