# 采用来源、当前状态与合理合镜

## 读取职责

现行导演稿id是镜号，scene是显示场景，body是采用完整声画，source_text为原文，duration_seconds为预算，notes为局部提醒。场级context含语言、画幅和采用条件，不能只读body。来源只读；正文与结构化对白真实冲突时定位，不擅自择一覆盖。

原文栏可能重复同一发言；实际口播只取body片段或已采用明确对白，不再演一遍原文。外部Excel／扫描件／多媒体由Agent读取，脚本不自动拆戏；文字归为P001仅为局部来源定位，不证明正式分镜已经形成。

## 每组有自己的初态

身份与固定物继承，站坐、方向、位置和持有按当前源镜时点恢复。前组已展开信纸，后组写“手持展开的信纸”；不能为了独立性再写“再次展开”。前组仅递到面前，后组不能套用后文“已抱在怀里”。出画不等于离场，新机位重新看见不自动是重复动作。

相机左／右是当前投影，不是人物身份。临时预演造型不自动晋升成片资产，采用人物参考不等于采用该图机位。仅可改变句式，不改变主体、对象、先后、否定、程度与结果。

## 三种边界分开

真实结束：明确换场、时间／现实层断裂，或当前具体事项收束后转入另一独立事项。提交分段：事项仍在进行，但容量或用户明确要求在既有源镜间分开。Cut／节拍：换观看、说话人、转身或直接反应，本身不决定分组。

合镜是一次提交中的多镜，不是一镜到底。G=[Sa…Sb]必须为完整来源序列的相邻完整镜；组串接恢复本轮原序。scope可选不连续范围，不允许重排，也不能抹掉两端之间的原镜。

本项目Σd≤30秒；已知实际服务上限更低时取较低值。小数精确保留；未知时长不合多镜，单镜超限保留完整Prompt并定位当前条件不满足，不加速、删对白或私拆。

## 用相似情境比较，不用关键词裁决

以下是虚构方法样例，结论需由采用稿实际支持：

| 镜头链 | 判断 |
|---|---|
| 宣布要求→惊愕→追问→解释，28秒 | 同一事项尚在回应；换人和话后反应不是自动断点，容量允许可比较同组 |
| 要求已处理→同场开始宴席安排，21秒 | 若已明确开启另一事项，则分组；同场与剩余容量不覆盖真实结束 |
| 起步离开→被叫住→回头回应 | 看离开是否仍被当前互动改变，不因“起步”机械断开 |
| 连续事项20＋11秒 | 只能在已有源镜间分提交，不把31改成30，也不补剧情停顿 |
| 旧稿在某镜后分组 | 仅历史位置不是语义证据；实际用户要求保留的分段仍有效 |
| scope为01、03 | 不可合成相邻组；02未被选中不等于从原源序消失 |

检查断点时看还欠什么直接回应／动作后果，下一镜是否开始另一事项；必要时连看前后数个组，不机械合两个旧组。不要求刺激和反应总在同组，容量不足仍可合法分提交。

## 最小记录与机械检查

仅在需要时使用context.boundaries，每项after用原样镜号，kind为semantic_end、scene_change、time_break、reality_break、submission_split或historical_split。前四类是明确边界，submission_split是有效提交限制，historical_split不禁合；有效限制用一句reason说明。不得为N−1位置强制填表。

旧式after/reason未分类时待复核；不跨时可保留原稿，拟跨时先明确用途，不静默释放用户可能保留的限制，也不全归语义结束。程序不从reason猜kind，不把旧组尾批量改semantic_end。

scene_keys只补真实缺失，不能覆盖已有scene_id或明确场标。同场不同区域不靠字符串差异切场；两个已知不同场次不能由一个未知项抵消。operation_id限定边界实际作用范围；原样"01"不等于1或"O1"。

程序检查显式ID、覆盖、原序、相邻、精确求和及已声明边界；语义仍由Agent回读。图像过程不增加时长，跨Cut的同一次发言不重复。范围结束不等于剧情已结束，不补结局。
