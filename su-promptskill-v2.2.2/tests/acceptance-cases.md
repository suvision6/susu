# 专业验收样例

以下期望用于后续专业/媒体验收，不把离线机械通过冒称真实视频通过，不作为每次任务新增审批。

| 编号 | 情境 | 应观察的结果 |
|---|---|---|
| P-T01 | 宣布、惊愕、追问、解释 | 识别同一未结束事项，换人不自动断组 |
| P-T02 | 同场另一项安排开始 | 不以同场和剩余容量覆盖真实语义结束 |
| P-T03 | 连续事项20＋11秒 | 原镜边界分提交，不把31改30或补停顿 |
| P-T04 | 原序选01、03 | 不伪装相邻源镜 |
| P-T05 | 31秒单镜 | 保存完整稿，局部反馈，不私拆或加速 |
| P-T06 | 30张库存，本组只上传3张 | 只在本次可访问范围内采用和排除 |
| P-T07 | 不同单元上传不同子集 | 各组范围独立，不继承另一组素材 |
| P-T08 | 未知范围与明确无素材 | 省略和[]区分，兼容路径不冒充传输证明 |
| P-T09 | 跨组递匣但尚未接过 | 不套未来终态，不重复前组动作 |
| P-T10 | 内心／现场画外及重复发言 | 原声位、次数、顺序保持，跨Cut不重复抄全文 |
| P-T11 | 硬时间点与小数预算 | 叙事时间表达保留，不伪称页面总长保证切点 |
| P-T12 | 缺母版和旧稿复验 | 缺口局部化，旧validate不追认证新语义，载体正文一致 |
