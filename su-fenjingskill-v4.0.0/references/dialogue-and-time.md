# 实际声画估时：台词计口播量，动作与环境计过程

镜长是画面与声音实际占用的时间，不是读完分镜说明需要的时间。本方法同时防止台词说不完和描述写得长就把镜头拖长；不以统一缩短、提速或加长修复两种相反错误。

## 一、先辨认“发生的事”和“描述的状态”

| 内容 | 怎样估时 | 不做什么 |
|---|---|---|
| 实际对白、旁白、确实播放的OS | 中文按实际口播汉字；英文按实际口播词，再使用已选口径 | 不计角色标签、表演括号、引用区副本、标点、摄影说明、被再次引用的重音词 |
| 伸手、起身、步行、递物等动作 | 按完成该动作的距离、阶段和表演方式估计 | 不按动作描述的字数换秒，也不对每个动词统一加一秒 |
| 目光、态度、停顿、呼吸等表演 | 判断是否有实际过程、发生在哪里、是否已含在口播时间内 | 不把每个情绪形容当成新的停顿，不把持续状态反复表演 |
| 日景、服饰、座位、已有背景、固定构图 | 作为当时已存在的视觉条件；不另占一段时间 | 不逐个物件或形容词累加时间，不将整段环境描写除以语速 |
| 门逐渐开启、人物进入、光线变化、环境揭示 | 按真实发生和观众必须读到的信息估计 | 不因有环境信息就一定另拍空镜或补统一环境余量 |
| 独立建立空间或静默观察 | 依据明确的观看任务或来源给定的持续时间 | 没有对白不等于零秒；不把必要空间观看一概压缩 |
| 机位、构图、景别标签、原文引用及备注 | 不直接作为口播或时长事件 | 不把解释文字算成演员需要演出的时间 |

一段详细服装说明可以与三秒台词同时可见；一句“等了半分钟”仍需三十秒。文字长短不能替代事件时间。镜头运动有必要的真实过程时要容纳，但运动、声音和演员动作能同时发生，不分别加总。

只从来源及镜头中实际播放的发言提取口播量；自然描述中为解释重音再次出现的词句不是第二次发言。原文真实重复则按次数保留。计数工具只接收已辨认的台词，不把“引号内所有内容”自动当作声音。

## 播放正文先完整，才有可核对的计时对象

实际声音在当前镜头正文直接写成`角色（声位）：“原文片段”`，可以嵌在连贯动作描述中，不新增一列。画内、画外、前景背身、OS等按当前画面与来源说明；别把背影入画又声称角色完全在画外。保持标点属于字面保护，标点本身不进入口播字数。

“某人说完整句”“声音接着传来”“以某几个词落下声明”都不足以确定实际播放。原文栏只提供出处，不能作为运行时补对白的隐性后备。新稿的同一次发言片段拼回后要逐字等于原文，真实重复按原次数保留。

## 二、前期选定语言、速率和口径

用户给定的本段时间、音轨或实际试读优先。无实测时，从下列用户参考结合本场表演选定数值，说明含／不含通常停顿，称为计划假设。候选库来自《影视剧与短片语速规范指南 - Google Gemini》（2026-09-03），不是统一行业标准或人体极限。既有第16集某段最低秒数不自动绑定第17集新台词。

数字、日期、英文缩写先按实际读法计量；读法仅用于测量，不回写原文。双语参考译文不重复演出。混合发言按实际语言片段估时，无声口形不算有声对白，但真实口形表演仍可占时间。

### 载体候选（原资料区间）

| 载体 | 中文字／分钟 | 英文词／分钟（WPM） |
|---|---:|---:|
| 微短剧／竖屏短剧 | 260–330 | 160–200 |
| 流媒体平台剧集 | 200–260 | 135–165 |
| 独立短片 | 140–200 | 100–140 |
| 院线长片电影 | 160–220 | 120–150 |

### 题材候选（原资料区间）

| 题材 | 中文字／分钟 | 英文WPM |
|---|---:|---:|
| 律政／医疗／行业商战 | 280–340 | 180–215 |
| 快节奏喜剧／黑色幽默／荒诞 | 260–310 | 165–195 |
| 悬疑／惊悚／犯罪推理 | 130–300 | 95–185 |
| 动作／军事／硬科幻救援 | 230–270 | 150–180 |
| 文艺／都市情感／亲情伦理 | 150–200 | 110–135 |
| 历史／古装／史诗奇幻 | 160–210 | 120–140 |

载体和题材给不同参考，不相乘、不机械求交集。正式、迟疑、愤怒、喘息可以有不同速度；情绪有力不自动提速。选值若因真实样本超出区间，记录有用依据即可，不建立越界审批。不要把一个场景的校准推广到全剧所有角色。

## 三、同一种停顿只计一次

优先使用包含通常短顿的整段发言速度；用户资料的不同计量表不能未经区分一起相加。

```text
中文发言秒数 ≈ 60 × 实际口播汉字数 ÷ 中文字／分钟
英文发言秒数 ≈ 60 × 实际口播词数 ÷ 英文WPM
```

含通常短顿时，不再按每个逗号、句号加秒；“缓声”“一字一句”已影响选用速度时，不因为同一个表演词再次放慢。明确超出样本的长停、哽咽或恢复，才估尚未包含的部分。采用实测纯发音速度时，再加入实际尚未包含的停顿，不同一段用两套口径。

无实读时保留估算不确定性，但不把不确定性变成每镜固定安全余量。明确需要的停留是创作选择，写进实际声画过程；泛泛的“留余韵”不能为已填过长秒数补理由。

## 四、先把过程放在时间上，再分配镜头

对一个连续段落，理解台词、动作、环境变化与必要观看的实际起止：

```text
T段落 = 最后一个必须完成的声画过程结束时点 − 段落开始时点
```

这不是仅对各事件时长取最大值，也不是把全部时长相加。动作0—4秒、发言2—7秒，该段到7秒；若动作必须在发言后再做，就按先后排列。正常重叠之外没有事件但确需等待的时间，也是一个明确观看过程，而不是未说明的空白。

若整个发言连同正常气口需要15秒，在其第5—8秒看听者：前镜5秒＋听者3秒＋后镜7秒，仍共15秒。若发言真的停下等听者回应3秒，才变成18秒。这个例子只说明时间关系，不规定每几秒切一次。

先估完整发言，再按实际声画切点分配片段，并同时核对两层：片段的口播时间是否容得下；各片段及真实动作、停顿合回后是否符合整段过程。整段余量不能替某个已固定切点的短镜说完本镜台词。

```text
同一已选口径：T片段 = 60 × 本镜实际口播量 ÷ 对应语言速度
本镜可用说话时间 ≥ T片段
```

可用说话时间须扣掉必须先做／后做且不与发言重叠的过程；同期动作不扣第二遍。有实录或已说明的局部发言速度时以实际依据为准，通用平均值不是人体极限。多声部重叠不能按声段数量机械相加。

例如190字／分钟时，15字约4.7368秒，18字约5.6842秒，13字约4.1053秒。分别给4／5／4秒都低于本次均匀计划口径，不能以相邻镜更长抵消。可以保留切点并适当重分配秒数；也可在不改对白的前提下移动切点，但文字片段与秒数必须一起改。

小数可以保留。不要每段各凑整秒再加头尾余量，也不要为维持原合计向下取整到说不完。需要增加的非重叠表演有其独立依据，不以句子短于镜长就自动压缩所有停留。

静态背景、说话时的扫视、持续环境声、同期推镜，都可以被已有时间容纳，不各加一轮。“说着看向对方”不能改为说完再转眼；“话落才转身”不能因想缩时而改成同时。

## 五、反应镜：动作完成后，画面还要让人读懂

前期在已有项目条件中选定反应阅读节奏，不由“短剧”两个字自动采用枪战、追逐或冲击插帧的速度。当前用户的非动作型古装人物戏采用以下工作基准：**简单独立反应2—3秒起步，通常不低于2秒；关键的猛抬头、惊愕等优先给到3秒。** 这是本项目已确认的节奏，不是所有影视作品的生理下限，也不是所有镜头的统一最短长度。

“猛地抬头”要求起动快，不能把抬头拖成慢动作；但镜头不能在头刚抬完时就结束。需要让观众定位人物、看见反应发生，再读到瞪大眼睛后的持续状态。动作的速度与整镜的长度是两个问题。

| 本场镜头任务 | 起步安排 | 复核重点 |
|---|---|---|
| 单一、独立的惊讶／抬眼／短反应 | 2—3秒；关键反应通常3秒 | 清楚发生，加上动作后可读的状态；不要只计头动了多久。 |
| 怔住→辨认→恢复、张口→失语→绞帕等复合反应 | 通常需超过单一反应；可从3—5秒试排，按实际过程调整 | 每个确实需要的变化看得见，不能把3秒当硬上限。无新动作不等于无可读时间。 |
| 正在说话时的听者画面 | 在既有声音内安排足够的阅读窗口 | 已有4秒听者画面不再加3秒。若片段太短，移动合法声画切点，不重复对白；话后才发生的反应不提前。 |
| 群体反响、多个主体或移镜揭出反应 | 依据实际进入可读画面的先后安排 | 运动、遮挡和失焦期间并不都能读清反应；到位后要留可读结果，或删掉多余运动。 |
| 原文只写略停／转向的桥接 | 按该桥接本身和本场节奏选择 | 不按“无对白”一律分类为反应，也不因规则给每个短镜加长。 |

实际计时仍把过程放到同一条时间上：动作、声音、摄影移动可以重叠；关键表情需要在画框内并可辨认。表情已经在运动中清楚读到时，这段也算阅读时间；不能机械地把所有运动时间、动作时间和阅读时间再相加。

单人惊愕示例（工作计划而非实测）：切入时即见面孔，前约0.5秒完成迅速抬头，随后保持惊愕目光至3秒结束。用2.5秒读到原有反应，不补一次吞咽、转眼或对白来填满。另一场若确有更短的冲击剪辑要求，可另选其节奏；不得用这种例外绕过当前用户的2—3秒要求。

复合示例：张口欲言却止住，随后手中帕子收紧。若需要从面孔摇到手部，必须给两处可读的时间；若现有时长不足，可以取能同时读清面孔与手部的中景，避免来回摇镜。镜头时长和摄影负荷一起决定，不先把2.5秒写死，再要求演员和相机赶完所有过程。

### 计划片长与剪辑余量分开

当前“预计时长”记录成片中计划使用的有效声画时间。关键反应的2—3秒应真实存在于采用画面，不是把1秒反应加2秒无内容的头尾。需要额外生成剪辑余量时，在已有执行说明中按需记录，不反写成剧情时间，也不每镜强制加同样的余量。

当前普通生成的一源镜一Cut、同场语义连续且单次不超过30秒仍有效。额外采集／生成余量也占本次请求容量；不能因称其为余量就超限或跨场。遇到容量不足，应在既有源镜边界重组或放弃额外余量，不压缩已确定的台词和有效反应。本Skill不因此预先按30秒拆镜。

### 环境与动作仍按实际过程

环境不按字数计时，也不一律归零。空间建立、真实路程、环境揭示或独立观察按观看需求；作为背景已存在的环境不逐项增加。来源“同时／说着／随后／话落”决定事件先后。独立反应需要阅读，静态背景无须逐项占时，两者并不矛盾。

## 六、估时复核回到实际内容

长台词先核对实际口播量与所选速度，再问额外时间被什么真实过程占用、是否已在对白内发生、是否已经在相邻镜头发生。发现虚增直接修订时间与重复动作，不补新停顿圆旧数字；发现偏短则还原必要时间，不强迫演员吞字或加速。

本次第17集在190字／分钟口径下：48字约15.16秒，35字约11.05秒，49字约15.47秒。它们是口播基准而非完整镜长或实测；差额要由具体非重叠过程解释。原20的18字约5.68秒，给5秒又不足，同一稿可以同时存在估长和估短，不能统一打折。

第16集用户对原07至少16秒、原13至少19秒、原17约20秒的校准继续仅作用于对应发言。未知镜长保持未知，不填0；无实读时不得称真实最低秒数。工具只保存已经选择的镜长，不从正文自动算出艺术时长。

默认无生成字幕，后期另加；道具文字、无声口形与真实发言分别保留其来源职责，不恢复字幕阅读率或排版工程。
