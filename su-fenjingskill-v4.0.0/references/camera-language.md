# 摄影表达：专业标签与实际画面

本 Skill 把“摄影三要素”固定为 `【视角，景别，运镜】`，这是交付约定，不是把全部摄影设计压成三个词。三项使用通行术语，机位、朝向、构图、焦段、焦点和可见内容用下面的自然正文说明。

## 从已有覆盖走到具体摄影，而不是从默认标签开始

先保留已经成立的表演节拍、发言人／听者切换和关键反应时点。摄影设计在这些镜头内解决“从哪边看、画面怎样组织、是否运动以及如何停住”；不能为了用上某个器材撤掉听者覆盖，把长对白重新并成一镜。

在现有场级短段中写主要阶段的实际拍法，例如：从受话者肩后建立公开对峙；发言转向另一对象时换成侧面关系；关键落点移出遮挡或靠近主体；物件交接时跟随动作；反应成立后稳定停留。阶段由戏决定，不固定段数，不另交摄影计划表。它应指导镜头正文，而不是一段“权力逐步加强”的抽象总结。

逐镜的选择顺序是 **关系构图 → 机位与角度 → 运动与稳定方式 → 可读时间**。已经合适的固定镜头保留；存在关系变化、位置迁移、信息显露时，要实际评估过肩、前景、俯仰和移动的作用，不把“固定也合法”当成免做摄影设计的理由。

## 可直接用于设计的摄影方法

| 观看任务 | 可用方法 | 正文必须让执行者读懂什么 |
|---|---|---|
| 让一句话明确作用于对方 | 过肩、带关系单人、前后景 | 前景是谁或什么；相机在哪一侧；主体面孔是否被挡；焦点在哪。不要同时宣称看清前景背身者的神情。 |
| 从围观中隔离人物或揭出关系 | 前景遮挡与移出遮挡、短横移／弧移 | 起始遮挡、同侧路线、显露的关系与停止画框。不能凭空放一个新人物或道具充当前景。 |
| 读坐立、亲疏或对峙位置 | 适量俯拍／仰拍、侧向观察、干净近景 | 相机相对主体眼线和身体的位置；实际看见的表情与环境。俯仰不是身份或强弱的自动函数。 |
| 在话语落点贴近发言或反应 | 有起止的前推／拉出 | 从什么景别到什么景别；何时开始和停下；前后关系怎样改变。焦距未变时叫机位前移，不叫变焦。 |
| 在同一画面中交代转向或新对象 | 左右摇、上下摇 | 明确起止朝向；需要读的人是否全程或在所需时点可见。跟随目光摇向目标会离开发起者，不等于仍看得到他的挤眼或笑。 |
| 让人物或重要物件的位移成为观看 | 侧跟、后退伴随、跟后或短弧跟随 | 跟随谁、在什么一侧、距离与高度怎样保持、何处减速落稳。不把演员停步后镜头无止境漂移。 |
| 连续行进、绕开遮挡但保持平稳 | 斯坦尼康（Steadicam）／稳定器式移动 | 用“稳定侧跟”“前方后退伴随”等真实路径组织，再说明平稳、水平线和启停质感。器材名不是路线，也不是自动的一镜到底。 |
| 让关键反应完整落地 | 适合的中近景／近景，固定或先动后稳 | 动作发生时能读面孔；运动结束后表情仍可读。摄影变化服务表演，不抢走反应的观看时间。 |

前景、过肩属于构图关系；俯仰属于视角；推、拉、摇、移、跟属于运动；斯坦尼康属于支持与稳定方式。首行仍为三要素，具体关系和稳定质感进入正文。可写“【平视，中景，侧向跟拍】”，正文写“采用斯坦尼康式平稳侧跟，沿人物左前方通道同速移动，停步时共同减速”。不把“斯坦尼康”单独填成运动的全部内容。

AIGC不要求真实租用这些器材；这里描述的是影像应呈现的运动特性，不保证某个模型听见器材名就能完成。长对白该切听者时仍切，不能为一次稳定器移动跨越已确认的关键反应切点。

## 给一次运动完整的画面过程

自然正文写清 **起始画框 → 触发／过程与路径 → 停止画框** 即可，不增加四五个必填字段。优先给一个主导运动，需要时加入保持主体的摇摄，不堆“前推＋环绕＋变焦＋下摇＋上摇”来表示丰富。

例如，递匣的源动作已存在：相机从人物斜前方同侧伴随，跟着捧匣者走近受领人，递出时减速成两人侧向关系，后续反应可清楚读到。不能只写“跟拍木匣”而缺少持有者、接收位置与最后画框。

反例：镜头要看人物转头、挤眼和笑，却把相机顺视线摇向画外另一人。这个摇法会丢掉目标表演。应留在发起者的正面偏侧，或在身体确实转动时用小幅同侧弧移保住面孔；不是每次转头都必须摇镜。

## 固定与运动要形成关系，不以比例判断

平视可以是过肩、侧面或带前景的不同机位，不代表离地高度相同。问题在于连续镜头是否都退化成同一种无关系的正面照片、所有推进是否都没有变化的终点。不要通过把“平视”改成“微仰”却保留原正文来改善统计。

也不要给每个反应镜都强加运动。一个正在移动的群体镜，接一个干净、稳定且停留足够的单人反应，已经形成摄影与节奏的对比。对真正同质的段落重选实际画框；不建立平视上限、固定上限或强制集齐器材的数量规则。

坐起时，相机保持高度并上摇与同步升高维持平视，是两种不同的观察。新切换机位各自成立即可，不要求把摄影机搬动拍进剪切之间。机位与身体高度、焦点、遮挡的关系写清，不要求逐镜厘米数或权力—高度曲线。

## 三项分别回答什么

| 项 | 回答 | 常用表达 |
| --- | --- | --- |
| 视角 | 镜头以什么角度观察主体 | 平视、俯拍、仰拍、顶拍；需要时说明倾斜角度或连续变化 |
| 景别 | 主体或细节在画框中占多大范围 | 远景、全景、中全景、中景、中近景、近景、特写、大特写 |
| 运镜 | 摄影机／镜头怎样形成连续画面 | 固定镜头、前移、后移、横移、上摇、下摇、左摇、右摇、跟拍、弧线移动、升镜、降镜、变焦推近／拉远 |

词表是常用示例，不是封闭白名单。采用其他专业方法时，说清它实际怎样发生。方向和速度可以修饰术语，如“缓慢前移”；同一镜内景别发生连续变化可写“中景→近景”。不要用“切到某人”伪装运镜。

人物景别以实际裁切和所需阅读为准：中景可容纳腰部附近的动作，中近景集中胸部以上，近景更集中面孔；为某个动作需要改变画框时如实说明，不能一面写近景，一面声称读清画外的腰间双手。过肩、双人、框中框描述构图，不替代景别与视角。

## 容易混用的词

“竖屏”是画幅，“长焦”是焦段／透视选择，“靖王”是主体，“主位”是位置，“上下构图”是布局，“反打／切入／组接”是剪辑关系；都不能替代缺失的三项。

摇镜在既定机位转动镜头朝向，升降镜改变摄影机高度。前后移改变摄影机位置；变焦改变焦距，不自动等于机位移动。调焦改变清晰平面，不等于切镜或移动摄影机。这些方法可以组合，但正文要能解释其起点、变化与结束画面。

以下用同一坐起动作比较两种摄影选择，仅说明相机条件如何产生标签，不作为通用拍法：

```text
【平视→仰拍，中景，原地上摇】
摄影机在案前斜侧，以坐姿眼线高度开画，容纳人物与案沿。人物放下茶盏后起身，摄影机地面位置与高度不变，原地上摇保持其上身可读；收尾从较低位置看站立者。
```

```text
【平视，中景，升镜】
摄影机在同侧以坐姿眼线高度开画；人物起身时同步升高摄影机，保持面对其上身的平视关系。相机实际升高，而不是只写“始终平视”。
```

这两个方案都要有相容的场地与设备条件；采用哪个取决于本场的观看需要。其动作与机位为方法示例，不是从用户第18集原文恢复的内容。

第一行只提供专业锚点，正文使其成立。不能以三项写齐、括号数量正确代替空间复核，也不因同一组专业标签重复就判定镜头单调。

## 先选有效画幅，再安排构图

画幅在前期决定，不能在输出阶段才裁图。本表提供方法，不提供景别配额：

| 有效画幅 | 摄影选择重点 | 要核对的实际条件 |
|---|---|---|
| 9:16 | 人物和关键反应优先考虑中近景／近景；多人用成立的过肩、纵深或独立观看组织 | 面孔、胸前动作能否同时读到；横向运动是否出窄画框；必要全景仍可保留 |
| 16:9／1.85:1 | 横向人物关系与纵深一起安排，共享与隔离按节拍选择 | 同框不代表细微表情可读，焦点、遮挡与景别仍要成立 |
| 2.0:1／2.35:1／2.39:1 | 横向距离、负空间、多人层次与运动路径 | 宽画框不强迫大全景，不忽略关键面孔和竖向动作 |
| 4:3 | 较集中地组织身体、中心和纵深入口 | 不自动等于文艺或慢速，不为了多人同框把表演缩小 |
| 多画幅 | 明确作用段落、转换位置和各自构图 | 不把导出裁切当作导演变幅，仍保持剧情与镜头定位 |

人物景别可用ECU／CU／MCU／MS／MLS／FS／LS等常用缩写辅助对照；以实际裁切为准，不将不同体系的边界强行写成唯一标准。平视可对应eye-level、俯拍high-angle、仰拍low-angle；pan是左右摇，tilt是上下摇，dolly是位置移动，zoom是变焦，rack focus是调焦。英文Prompt继承同一摄影含义，不按字面混译。

## 竖屏中的可见性

画幅纵向延长不会消除遮挡，也不会把人物的身份高低变成身体高差。主位在后方，不代表从当前机位可看见它在另一人头顶。上摇只改变朝向，不能修复同轴身体遮挡。

人物反应以面孔、视线或身体为观看重点时，先给合适的中近景／近景；空间确实需要展示时再使用全景或中全景。这是按当前任务选择，不设置竖屏近景百分比，也不禁止竖屏全景。

本项目若要求中近景为主，应把它落实为实际画框，而不是给所有景别加“竖屏”二字。多人关系可用成立的前后位置、过肩或正反打；不要为容纳更多脸把镜头退得很远，又继续标中近景。
