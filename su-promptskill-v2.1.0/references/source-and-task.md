# 来源与任务

用户锁定的当前输入是内容权威；不要求特定 Skill、合同或版本。文件副本、用户授权编辑、素材观察各有不同职责，不能互相冒充。

## 输入路径

已有导演分镜：保留镜号、顺序、场景、摄影、调度、表演、声音和一源镜一 Cut。缺摄影或时长不自动补。
未分镜剧本：事件清楚时写事件型 Prompt，不伪造摄影设计和源镜号；确需导演选择的局部列为待决定，其他可独立部分继续。
Markdown／Excel／文档：先由 Agent 完整读取原载体并识别已有镜号。必要时建立 JSON 只读副本，保存原文、定位和原始文件说明，不要求用户填写内部字段。

CLI 直接读取 UTF-8 JSON 和纯文字。JSON 支持 shots/source_shots 及镜头数组；纯文字作为 P001 源段供 Agent 转写，不把解析能力冒称为完整剧本理解。复杂表格、扫描文档和多模态素材由宿主 Agent 先读取；命令行不做 OCR 或媒体识别。

## 已知结构的保留

source_shot_id/shot_id/id 沿用；没有镜号的内部源段定位不冒充导演新镜头。
staging 保留主体、画内／画外主体、调度与表演；camera 保留已有摄影字段与运动条件；sound 保留对白与声音子项；continuity 保留状态及方向。
source.dialogue_lines 是已提供的对白字面和说话人权威，sound.dialogue_segments 负责来源已有片段及声位。
顶层与嵌套明确冲突须定位到该单元；版本未知不是错误。

原始输入全文和所有字段都保存在 Plan；提取并不授权删除未知执行信息。
未知非空字段和 execution_text 会标记待复核。Agent 必须回读，保留独有画面事实；审计理由留在报告，不能整段丢掉或整段灌入正文。
剪辑入口／出口不是摄影机首帧／尾帧，素材首尾帧职责也不是新画面状态。

## 生成、编辑、延长

每个 operation 一个 primary：generate、edit 或 extend。正常生成默认 OP001。
编辑：唯一已观察母版、明确修改范围、未修改部分保持。合法编辑授权覆盖指定范围的一般保真约束，不能据此扩大修改。
延长：唯一已观察延长源、方向、真实边界、运动与声音状态。只延长，不同时改写原片。
编辑后延长：有序操作；中间视频未生成时，后一步只能是计划，submission_ready=false。独立操作不受牵连。

authorized_dialogue_edits 仅用于用户明确批准的对白编辑：包含 operation_id、source_id、event_id、text、user_instruction，并用 context.source_sha256 绑定当前来源。一般润色不得使用这项授权。原文不回写。

## 缺失与续做

非核心素材缺失时在主稿去除无效引用；核心身份、母版或延长边界缺失只影响相关单元及真实依赖。
来源有关键冲突时不猜；允许保留最佳草稿，但不得标可提交。
局部修订复用已经确认的内容；源文件变更后旧复核 hash 不再有效。先判断受影响范围再更新主稿与复核，不无限重写全部。
