# 单元与连续性

合镜只组织一次提交，不修改导演源镜。已有源镜恰好映射一次 Cut；同一来源用于不同明确 operations 时，分别在各操作内保持完整顺序。

默认安全单镜。没有充分判断不合镜，不再先填满 N−1 份十维表单才交付。
实际要合的边界在 context.joins 保留 left、right、reason，并以 source_sha256 绑定原始输入。正文里仍有对应的 Cut 1、Cut 2。

```json
{"source_sha256":"由实际输入计算的64位摘要","joins":[{"left":"SH001","right":"SH002","reason":"同场连续动作，边界状态明确承接"}]}
```

这是 Agent 内部记录，不要求用户填写。没有 join 记录时，用逐镜主稿继续；真正的 hash 失配或来源冲突不能静默绕过。
旧 grouping_review 可作为参考：读取原始依据后为当前输入重新绑定。旧 canonical 的 observed hash 与原始文件 SHA256 不是同一概念，不能互换或伪造。新版不再由动态规划替 Agent 决定分区；历史算法保留在旧版，不成为新版运行时必需。

跨场景、时间或现实层断裂不在同一连续生成单元中乱合。只有共同场景，不足以证明动作或叙事兼容。
相邻单元只承接当前时点已成立的身份、道具、视线、空间与声音。全故事中的未来事件和未来状态不提前进入当前目标。来源明确的回忆、梦境与预示画面照常保留，不按现实物理偏好否定题材。

时长来源可靠时精确求和；小数不取整，未知保持空白。请求目标时长不能反推各 Cut 时间。
未知时长保持单镜。单镜超限保留完整 Prompt，提示当前配置不可直接提交，不擅自拆源镜。

Cut 内允许多个有序动作或阶段，也允许静态等待和持续观察。没有“恰好一个主要状态变化”标签门禁。
平台容量只影响可提交条件，不许可删掉故事；没有经过核实的通用模型上限不写成硬事实。
