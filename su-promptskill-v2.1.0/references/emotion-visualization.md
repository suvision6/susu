# 受控情绪外化

中文润色不是新增表演的授权。已有 visible_behavior 或 staging.performance 时，用原有行为，不另加微动作。

只有明确抽象情绪、没有可见行为时，允许能支撑原情绪且不改变执行事实的最小外化。来源情绪也可以直接保留；找不到合适外化时不强迫增加动作。
保护人物目标、关系、情绪走向、位置、道具、时点、摄影、声音和结果。不能因“不安”自动看向来源没有的门，也不能自动加入呼吸声或吞咽。

派生记录与原文分开，context.emotion_visualizations 使用源 ID、basis_emotion、text。basis_emotion 必须与来源一致；正文使用 text，记录不能回写为来源表演。既有 guardrails 可兼容读取，但不要求 Agent 填一套新的布尔表单。

程序只检查触发条件、来源对应与记录是否绑定正文。派生是否真的没有增加连续性负担，由 Agent 回读原文后判断，不以程序通过冒充语义证明。
