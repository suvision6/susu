# 角度与摄影机运动执行规范

本文件是 [shot-design.md](shot-design.md) 第 4 节「摄影机与调度」的执行补充，防止镜头角度和运镜选择被默认填充为「平视 + 固定」。它是每场拆镜时 `camera` 字段与第五列摄影三要素【角度，景别，运镜】的强制审计依据。

## 1. 角度选择是强制导演决策

每镜的 `camera.angle` 必须基于至少一项具体叙事需求主动选择，不得因「省事」「安全」「不犯错」而默认填「平视」。选择前检查以下维度：

- **人物权力关系**：低位仰望强者 / 威胁 / 幻象；高位俯视脆弱、被审视、命运落差。
- **空间揭示**：高角度建立环境全貌；低角度强调垂直空间或出口。
- **主观 / 半主观**：从人物视线高度出发，或故意偏离视线高度制造疏离。
- **情绪距离**：平视用于共情；微俯 / 微仰制造轻微不安、神圣感或压迫感。
- **形体与调度**：侧角度展示人物走位和画面纵深；正角度强调对峙或直面。

**FAIL 条件**：最终镜头集中某单一角度（如平视）占比超过 60%，且无明确风格理由在 Gate 1 `director_profile` 中声明。

## 2. 侧角度强制规范

80% 的镜头采用侧 30° 或侧 45° 视角拍摄，特别是人物近景、特写。

- 「侧 30° / 侧 45°」指摄影机位于人物正面朝向的侧前方或侧后方，不是正侧面轮廓。
- 优先作用于人物近景、特写、过肩镜头。
- 正面镜头只在以下情况允许：
  - 直接对峙、审问、告白等需要「面对面」张力的对白；
  - 人物直视镜头形成打破第四墙或强烈主观效果；
  - 证件照、监控、镜子反射、特殊媒介画面等视觉设计。

**FAIL 条件**：人物近景 / 特写中正面镜头占比超过 30%，且无 Gate 2 规划说明。

## 3. 开场大景别镜头的角度规范

每场戏的开场镜头如果是大全景、全景、小全景，默认采用微俯视 + 摇臂下降来表现；如果是中景、近景、特写则不适用本条。

- 「开场镜头」指每场第一个规划单元（PU001）。
- 微俯视 + 摇臂下降形成「从世界到个人」的入口，让观众先获得略高于日常的地理信息，再降到人物层面。
- 若导演在 Gate 2 明确选择其他入口策略（如从地面仰拍、从遮挡物后横移、从身体局部进入），需写入 `directing_plan.pov_flow` 并说明具体理由。

**FAIL 条件**：大全景 / 全景 / 小全景开场既未采用微俯视 + 摇臂下降，也未在 `directing_plan.pov_flow` 中声明替代入口策略。

## 4. 微俯视 / 微仰视的多样性约束

多用微俯视和微仰视增加视角多样性，但禁止整场戏全是这种组合。

- 每场戏的最终镜头角度分布应至少包含 3 种不同角度策略。
- 允许的「角度策略」包括：平视、微俯视、微仰视、明显俯视、明显仰视、侧角度、肩后、主观视角。
- 单一场景正面镜头占比超过 40% 为 FAIL（特殊对峙场景除外）。

**FAIL 条件**：某场景全部镜头只在「微俯视」和「微仰视」之间切换，无第三种角度策略。

## 5. 固定镜头比例与运动动机规范

固定镜头是合法运镜选择，但比例不能过高；情节比较慢的情绪戏份默认采用极缓慢推进、极缓慢拉远、极缓慢平移的方式，需要根据剧情来推理，不可机械地上一镜推进、下一镜又拉出，反之亦然。

- 整场固定镜头占比不得超过 50%。
- 每次推 / 拉 / 移必须绑定具体的叙事或情绪变化：
  - 推进：靠近秘密、靠近情绪、放大发现；
  - 拉出：揭示环境、制造疏离、呈现关系变化；
  - 平移：跟随视线、跟随遮挡物、连接两个空间信息。
- 情绪慢戏允许连续固定镜头，但需由剧情决定。重大信息揭示后的余波、观众需要主动注视画面细节、角色静止凝望时，固定是合理选择。是否连续固定应在 Gate 2 的 `directing_plan` 或规划单元目的中说明。

**FAIL 条件**：
- 整场固定镜头占比超过 50%。
- 相邻两个镜头出现无理由反向推拉（推进 → 拉出，或拉出 → 推进）。

## 6. 第五列渲染与内部一致性

- 第五列统一格式为【角度，景别，运镜】+【画面内容】。
- `camera.angle` 必须与 `execution_text` 中描述的摄影机相对位置一致。例如「微俯视」不得在正文中写成「从地面仰望主体」。
- `camera.movement=固定` 不得在 `execution_text` 中同时出现推进、拉出、横移、跟随、环绕或摇摄。
- 已登记的 `over_shoulder`、`subjective`、`insert`、`environment` 等 `framing_mode` 必须与角度描述互相兑现，不得矛盾。

## 7. 与导演风格的关系

本规范是 `director_profile` 的执行约束，不是风格改写器。

- `camera_energy=static` 仍受 50% 固定上限约束，但允许更多固定镜头；连续固定需在规划单元目的中说明剧情理由。
- `camera_energy=responsive` 和 `assertive` 应更积极地使用侧角度、微俯/仰和运动镜头，但仍禁止无理由反向推拉。
- `space_strategy=establish_then_enter` 更依赖第 3 条的开场大景别微俯视规范。
- `space_strategy=embedded_reveal` 更依赖侧角度与微俯/仰在动作中逐步揭示空间。

## 8. 机器校验边界

机器可审计以下明确指标：

- 单角度占比是否超过 60%。
- 整场固定镜头占比是否超过 50%。
- 相邻镜头是否出现无理由反向推拉。
- 角度描述与 `execution_text` 是否矛盾。
- 大全景 / 全景 / 小全景开场是否缺少微俯视或替代声明。

机器不裁决角度是否「好看」、某镜是否应该更俯或更仰；这些属于 Gate 2 导演判断，但需在规划材料中体现。
