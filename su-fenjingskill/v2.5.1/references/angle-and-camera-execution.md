# 角度与摄影机运动执行规范

本文件是 [shot-design.md](shot-design.md) 的 DOP 规划与执行补充，负责在 Gate 2 前检查视角、机位、构图、透视、焦点、空间策略与运镜计划，在终稿检查 camera 是否兑现规划。比例只触发导演复核，不是多样化配额。

## 1. 视角高度是逐镜导演选择，不是配额

每个 Gate 2 `visual_plan.angle` 表示纯粹的视角高度／俯仰关系，必须由当前镜头的人物权力、空间揭示、主观位置、情绪距离、形体调度、观察位置、物件尺度、遮挡、连续性或明确图形秩序推导。终稿 `camera.angle` 必须与它完全一致。平视、微俯视、俯视、顶视、微仰视、仰视，以及确有必要的低机位平视等都可以合法连续使用，只要与整场策略及镜头目的相符。

正面、侧面、背面、肩后和主观属于水平观察方向或构图关系，不是视角高度；应由 `position`、`framing_mode`、主体关系或构图字段表达。镜头、焦段、人物名称、场景名称和观看结果也不得混入 `camera.angle`。

不得因为“多样化”而机械轮换角度，也不得因为某角度出现较多就自动判定艺术错误。高度程式化的正面、中心或固定观看，同样可以是已确认风格的有效执行，但达到审计阈值时必须在 Gate 2 结构化说明，不能靠自然语言关键词豁免。

不得因为 `camera_energy=static`、场景情绪平静、整场观察位置稳定或上一镜使用平视，就把后续镜头默认复制为平视。稳定观看可以保持空间或构图秩序，但每镜仍须完成一次视角高度判断；判断结果可以相同，理由不能缺席。

## 2. 位置、构图与观看关系

- 侧角度适合展示走位与纵深，但不是人物近景的默认答案。
- 正面适合对峙、仪式、图形秩序、主观凝视或刻意疏离，不需要比例豁免。
- 肩后、遮挡、背面、共享构图和画外观看必须与对白观看权及空间关系一致。
- 中心构图、对称构图、边缘构图与不平衡构图都由 profile 和场景任务决定。
- 首镜必须兑现 `directing_plan.entry_strategy` 的 mode、观察位置、必需空间信息与暂缓信息；`pov_flow` 负责说明后续视点转移。
- 开场大景别没有默认摇臂下降。`spatial_establish` 要求建立必要空间关系，不等于限定大全景或固定运镜。
- 移动汽车且后续依赖车外目标、道路方向或交通遮挡时，默认先让必要空间条件可读；若采用人物、主观、关系或延迟揭示入口，必须有已确认的叙事收益，不能由通用后排覆盖机位代替入口判断。

六列表镜头头只显示 `【景别｜角度｜运镜】`。三项必须保持纯净：景别不写人物或场景，角度不写水平观察方向、焦段或主观结果，运镜不写构图结果、事件结果或动机。机位、构图、主体、焦点和空间策略仍是 DOP 必需信息，但只能进入内部结构与【画面内容】，不能伪装成第四个摄影元素。

## 3. 固定与运动

固定镜头没有数量上限。固定、推进、拉出、横移、跟随、环绕或摇摄都须有可说明的叙事、观看或情绪动机：

- 推进可用于靠近秘密、情绪或发现。
- 拉出可用于揭示环境、关系改变或疏离。
- 平移与跟随可连接视线、遮挡、行动或空间信息。
- 固定可保护完整表演、延长余波、维持制度感或要求观众主动观看。

相邻镜头允许采用方向相反的运动，但每次运动都必须有独立动机，起止画面不能互相抵消成无意义的填充。

`camera_energy` 只规定运动倾向：

- `static` 倾向克制或固定观看，但不等于全片平视、全片固定，也不豁免逐镜运动判断。
- `responsive` 让摄影机响应动作、视线、声音或关系变化，不代表必须持续运动。
- `assertive` 允许摄影机主动塑造信息与节奏，但不能制造来源外事实。

`movement_plan.class` 与终稿运动审计使用同一套归一化类别：

```text
fixed
push
pull
pan_or_tilt
track_or_follow
orbit
crane_or_boom
focus
handheld
vehicle_mounted
compound_move_then_fixed
```

`movement_plan` 必须包含 `class`、`trigger`、`speed`、`path`、`end_condition`、`hold_reason`。运动镜填写触发、速度、路径和停止条件；固定镜头只填写保持理由。运镜类别只用于归一化统计，不代替摄影设计。

终稿可在同一类别内精化设备说明，但不得改变已确认的触发、速度、路径或结束条件。

## 4. 透视、焦点与多区域空间

`perspective_intent` 只允许 `wide_spatial | natural_relation | compressed_distance | detail_isolation`。焦段毫米数可选。

同镜覆盖两个以上空间区域时，`spatial_strategy.type` 必须是 `foreground_background | deep_focus | compressed_depth | split_focus | blocking_reveal | sequential_reframe`，并以 `description` 写清主体分布、焦点／调度变化与观看路径。单一区域使用 `not_applicable`。

空间两端人物分别使用两个近景或特写时，不要求多区域策略，也不因距离判错；只检查空间建立、眼线、轴线侧别、银幕方向和切换。

## 5. Gate 2 坍缩复核与纵向几何

不设置“每场必须有几个俯拍、仰拍或运动镜头”的机械配额。机器在 Gate 2 确认前对 `angle` 与 `movement_class` 分别统计：

- 全片不少于 8 个规划单元且同一值达到 75%，触发项目级复核。
- 单场不少于 5 个规划单元且同一值达到 75%，触发场级复核。
- 单场 3–4 个规划单元时，只有 100% 相同才触发。
- 多场作品 100% 单一视角且没有结构化复核时直接 FAIL；不能用 `camera_energy=static`、自然语言里的“统一风格”等关键词豁免。

阈值命中后只有两种合法处理：调整视觉方案，或在 `shot_plan.visual_uniformity_reviews[]` 提交结构化导演复核：

```json
{
  "review_id": "VR001",
  "scope": "scene",
  "scene_id": "SC001",
  "dimension": "angle",
  "dominant_value": "平视",
  "reason": "保持父女眼线平等，让告别的权力变化只由距离和转身产生。",
  "style_anchor_ids": ["SA001"]
}
```

- `scope` 只允许 `project | scene`；项目级 `scene_id=null`，场级必须引用存在的场。
- `dimension` 只允许 `angle | movement_class`，`dominant_value` 必须与当前统计完全一致。
- `reason` 必须说明具体人物、空间、观看或叙事收益，不能写“风格需要”等通用词。
- `style_anchor_ids[]` 必须引用复核范围内已确认的锚点。
- 复核记录、分布和警告全部进入 Gate 2 digest；规划变化后旧复核若不再对应当前高占比模式会 FAIL。
- 8/9、9/11、4/4 以及 43/54 等近乎坍缩都必须被识别，不能靠只改一镜消除审计。

视角高度必须兑现机位和画面中的纵向几何：

- `position`、`logic` 或 `execution_text` 声明摄影机在主体上方、俯看、越过高处向下看时，不能仍写成无俯仰关系的普通平视。
- 声明摄影机贴地、位于脚边、主体下方或向上看时，不能仍写成无仰角或低位关系的普通平视。
- 顶视、俯视、仰视与低机位平视必须分别匹配真实摄影机高度和镜头朝向，不能只靠情绪性用词代替空间关系。
- 纵向关系不明确时不凭关键词机械改角度；只有物理位置和朝向可确定且与 `camera.angle` 冲突时判 FAIL。

## 6. 确定性 FAIL

机器只对可确定的矛盾判 FAIL：

- 终稿的观看主体、视角、景别、构图关系、机位、透视、焦点、空间策略或运镜计划与 Gate 2 `visual_plan` 不一致。
- `camera.angle` 与 `execution_text` 描述的高度或俯仰关系冲突。
- `camera.position`、`composition`、`framing_mode`、主体关系或已声明轴线互相冲突。
- `camera.movement=固定`，正文却同时声明推进、拉出、横移、跟随、环绕或摇摄。
- 归一化为 `compound_move_then_fixed` 的镜头，其实际运动所在时间块 `camera_seconds=0`。
- 运动缺少触发、速度、路径或停止条件。
- 多空间区域同镜呈现却没有可执行的空间策略。
- 镜头头不是恰好三个纯摄影元素，或把人物、地点、构图结果、主体关系、动机与揭示结果混入其中。
- 已登记的 `over_shoulder`、`subjective`、`insert`、`environment` 等 framing mode 没有在画面关系中兑现。
- 最终首镜及其入口连续过程未兑现 Gate 2 已确认的 `entry_strategy`：遗漏必需空间信息、提前泄露暂缓信息，或观察位置与 mode 冲突。

视角高度重复、固定镜头较多、正面或中心构图较多本身不构成艺术错误；达到第 4 节阈值时必须完成 Gate 2 结构化复核，确定性矛盾则直接 FAIL。无动机但尚不能机器确定为矛盾的摄影机行为，作为人工 WARN 进入 Gate 2 复核。

## 7. 与导演风格的关系

- `camera_energy=static` 可以让运动克制、让固定观看占多数，但不能替代逐镜视角高度与运镜设计，也不能豁免 Gate 2 复核。
- `camera_energy=responsive` 与 `camera_energy=assertive` 同样不构成运动数量或角度变化配额。
- `space_strategy=establish_then_enter` 可先交代空间，也可用稳定构图建立关系。
- `space_strategy=embedded_reveal` 可在动作中逐步显露空间，不等于必须侧拍或移动。

关键规划单元可通过 `style_anchor_ids[]` 登记风格应用或有意例外；普通镜头不强制逐镜引用。机器不裁决某角度是否“更好看”，也不靠镜头比例替导演做决定。
