# 厨房告别

Skill 版本：3.3.3
原始来源：示例剧本：林晓彤把钥匙放在餐桌中央，说“钥匙给你。”陈默问“你还会回来吗？”林晓彤答“不会。”两人隔桌站着。
本轮范围：厨房场景全文
设置：16:9；自然口语；无固定总时长

## 导演设计

### 原始输入
```text
林晓彤把钥匙放在餐桌中央，说“钥匙给你。”陈默问“你还会回来吗？”林晓彤答“不会。”两人隔桌站着。
```

### 厨房·剧情与情绪
林晓彤交还钥匙，克制地结束关系；陈默从等待转为最后一次询问。发言权按林晓彤—陈默—林晓彤转移，默认正反打，最后的短答落在她的面孔上。

### 厨房·暂定空间
林晓彤在餐桌北侧朝南，陈默在南侧朝北。机位均在两人连线东侧：陈默东侧朝西北拍林晓彤，林晓彤东侧朝西南拍陈默，视线分别朝画左与画右。钥匙落在桌中央，首镜保留手与桌面，不要求读物件上的文字。

### 声音与节奏
钥匙落桌声在短句前出现，问答按接话转镜。预计时长按动作和发言判断，切镜不另加停顿。
