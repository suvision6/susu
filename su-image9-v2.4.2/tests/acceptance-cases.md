# 专业与媒体验收样例

以下是后续视觉验收目标，不以合成PNG或文件检查冒称真实分镜生成通过，也不增加逐页确认门禁。

| 编号 | 情境 | 应观察的结果 |
|---|---|---|
| I-T01 | 只有文字无参考 | 正常预演，临时身份和布局一次定义并继承，不强制索图 |
| I-T02 | 先生成后镜再回补早镜 | 当前时点正确，不套后镜终态 |
| I-T03 | 递到面前、触碰、接稳、松手 | 必要阶段与持有关系正确，过程不新增Cut |
| I-T04 | 单格修改 | 不默认携带其余八格任务，不重生无关格 |
| I-T05 | 床铺右侧平视 | 区分场景/对象/画面左右，遵守实际相机参照和画内结果 |
| I-T06 | 三人反打 | 重新判断相关轴线，前景肩和目光对象不串人 |
| I-T07 | 55幅必要画面 | 不为六页删必要状态，完整九格用有用途延展补足 |
| I-T08 | 部分参考 | 限域采用身份/结构，姿势和旧持物不覆盖当前状态 |
| I-T09 | 源错、输入错、模型错 | 分别定位，输入正确时修真实图，不以失败图改锚 |
| I-T10 | 旧主稿无明确小节 | 保留完整兼容上下文，明确未隔离，不静默删除 |
| I-T11 | r02、换参考或换输入策略 | 旧批准不自动迁移，未改图原文件仍保留 |
| I-T12 | 混合画幅、净图、审阅与PDF | 有效框不拉伸裁切，标签在框外，最终版只排真实已确认版本 |
