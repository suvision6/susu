# Director Method｜导演读场与镜头动机

本文件只处理导演层面的场景理解、观看组织和“镜头为什么存在”。它不定义文件格式，不要求 Gate，不维护状态机。

## 1. 从变化读场，而不是从文本行拆镜

先把场景压缩为一句导演判断：

> 某人试图完成某件事，受到某种阻力；在某个时刻，关系、信息或行动发生不可逆变化。

至少识别：

- **起始状态**：人物进入本场时已经处于什么关系、目标和压力中。
- **显性目标**：人物此刻想获得、避免、隐藏或迫使什么。
- **阻力**：另一人物、制度、空间、身体、时间、秘密或自我矛盾。
- **戏剧问题**：观众等待哪件事发生或不发生。
- **转折**：信息、权力、决定、行动或情绪何时改变方向。
- **结束状态**：离开本场时，什么再也不能回到原点。

若文本没有明显转折，不要虚构。稳定积累、观察、等待、仪式、重复劳动和日常微变本身都可以是场景任务。

## 2. 观众位置

镜头设计前确定观众被放在哪里：

- **外部观察**：观众比人物更冷静，能读空间和关系。
- **关系视点**：观众被放在人物之间，主要感受距离、权力和交换。
- **人物贴近**：观众随某一人物获取信息，但不必采用字面 POV。
- **有限主观**：观众只知道人物知道的部分，空间和信息有意受限。
- **游移视点**：观看权在人物、空间或物件之间转移，但每次转移有明确动机。
- **全知结构**：观众先于人物知道危险、误会或因果，用于悬念或讽刺。

“谁在画面里”不等于“谁拥有视点”。视点由信息权限、情感距离、观察高度、声画关系和剪辑组织共同决定。

## 3. 信息流

把场景中的信息分为：

- **必须先建立**：缺失会让后续动作、方向或关系无法理解。
- **可以逐步显露**：让人物或空间在行动中被认识。
- **必须暂缓**：提前出现会破坏悬念、认知落差或主观体验。
- **可以留在画外**：声音、缺席、威胁、欲望或空间延伸比直接展示更有效。
- **必须落地**：某个词、动作、物件或反应需要成为观众明确接收到的认知点。

建立空间不等于使用大全景。可以通过共享构图、人物走位、视线、声源、前后景、遮挡或连续运动让空间可读。

## 4. 场面调度先于镜头

导演先决定人物如何在空间中行动：

- 谁主动接近，谁后退，谁占据通道或出口。
- 谁能看见谁，谁只能听见，谁被遮挡或被排除。
- 哪件道具改变关系、触发动作或承载记忆。
- 人物何时停下、转身、坐下、站起、交叉、越过、离开或进入。
- 关系变化是否通过距离、方向、层次、身体朝向或空间所有权呈现。

镜头应观察、组织或揭示这些行为，而不是替代行为。

## 5. 镜头动机

每个镜头至少有一个首要动机，必要时有一个次要动机：

| 类型 | 镜头服务什么 | 常见问题 |
| --- | --- | --- |
| 信息 | 建立、隐藏、揭示或重新解释信息 | 观众必须看见什么？何时看见？ |
| 情绪 | 让观众承受、期待、疏离或贴近人物状态 | 需要看面孔、身体、空间还是停顿？ |
| 人物关系 | 显示权力、亲疏、联盟、排除或交换 | 谁与谁共享画面？谁被切开？ |
| 空间 | 建立方向、距离、路径、阻隔或画外延伸 | 后续行动依赖哪些空间条件？ |
| 主观体验 | 限制感知、扭曲时间、制造身体或心理体验 | 观众知道多少、听见什么、失去什么？ |
| 节奏 | 加速、停顿、断裂、重复、蓄压或释放 | 为什么现在改变镜长或剪辑密度？ |
| 转场 | 连接场景、时间、空间、声音、动作或观念 | 前后镜如何发生关系？ |

动机必须具体到当前人物、动作、信息或空间。以下不成立：

- “丰富角度”
- “更有电影感”
- “避免重复”
- “增强氛围”
- “保持流畅”
- “来一个特写”

可以写成：

- “把画面留给听者，让画外问句先作用在她的身体上，再让回答出现。”
- “在钥匙落桌时切到细节，因为这一物件第一次把离开的决定变成不可撤回的事实。”
- “保持双人同框，直到其中一人越过门线，关系真正分裂后再切开。”

## 6. 镜头边界

一个镜头从某一观看状态开始，在它完成任务、失去张力或需要转移观看时结束。

开始点常由以下因素触发：

- 新信息进入。
- 人物进入新的行动或心理状态。
- 视点转移。
- 声音先行。
- 前镜动作、视线、图形或情绪提供接点。
- 时间或空间发生跳跃。

结束点常由以下因素触发：

- 信息已经落地，再停留只会重复。
- 反应需要被看见或被有意拒绝。
- 构图中的关系被人物动作重新定义。
- 声音把注意力拉向画外或下一空间。
- 观众需要突然失去、获得或重新组织信息。
- 镜头在沉默中达到压力峰值。

不要把每个动作完成都当作镜头结束。一个完整动作、表演、对话交换或空间穿越可能需要在同镜中持续。

## 7. 最少镜头原则

初稿从最少镜头开始：

1. 用一个镜头承载可以在同一观看组织中成立的连续过程。
2. 当观看主体、信息尺度、主观位置、空间关系或节奏真正改变时再增加镜头。
3. 检查每个新增镜头是否带来新价值，而不是重复同一信息。
4. 检查每个合并镜头是否仍能让观众清楚知道该看哪里、听什么和理解什么。

“最少镜头”不等于少镜头美学。动作、喜剧、惊悚、群像或高密度信息场景可以需要很多镜头；关键是每个镜头都有不可替代的作用。

## 8. Coverage 与设计型分镜

### 设计型分镜

优先用于：

- 场面调度、空间、声音和剪辑关系已被导演明确设计。
- 视觉结构本身承担叙事。
- 需要控制信息、主观体验或节奏。
- AI 视频或严格前期制作需要明确镜头。

### Coverage

只在以下情况下增加：

- 拍摄现场可能需要不同表演强度或节奏选择。
- 演员、动作、特效、儿童、动物、天气或场地带来真实不确定性。
- 用户明确要求安全覆盖。
- 连续长镜有技术风险，需要备份剪辑点。

Coverage 必须标注为备用，不得与主导演方案混在一起造成镜头冗余。

## 9. 观众注意力

每个镜头要明确注意力如何被引导：

- 构图中心、边缘和负空间。
- 光比、色彩、运动和焦点。
- 人物视线、身体朝向和动作路径。
- 声音方向、突然消失或声画错位。
- 剪辑后视觉重心的位置关系。

镜头中可以保留多义性，但不能因为设计含糊而让观众不知道当前重要信息在哪里。

## 10. 主动打破规则

可以为以下目的打破连续性或常规覆盖：

- 人物失去方向或控制。
- 关系发生断裂。
- 观众被迫重新判断空间或现实。
- 时间、记忆、梦境或主观状态发生跳变。
- 制度、仪式、压迫或荒诞需要反常观看。
- 动作或情绪需要突然中断。

任何违例都回答：

1. 观众会感到什么？
2. 观众会失去或获得什么信息？
3. 为什么常规连续性无法提供同样效果？
4. 何时重新建立可读性，或为什么不重新建立？

## 11. 镜头动机复核

对每镜做删除测试：

- 删除后，是否丢失事实、动作、信息或对白？
- 是否丢失人物关系或表演过程？
- 是否破坏空间、视点、节奏或声音连接？
- 相邻镜头能否承担同样功能？

如果删除后没有实质损失，优先删除或合并。若必须保留，重写具体动机。
