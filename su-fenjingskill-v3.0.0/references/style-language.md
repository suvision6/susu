# Style Language｜风格参考的导演化编译

本文件只在用户指定导演、摄影师、影片、类型或明确风格时读取。未指定时不要强制进行风格候选流程。

风格是镜头选择的偏置，不是剧情改写器、滤镜包或人名模仿。

## 1. 从人名转成可执行选择

用户给出创作者或影片参考时，提取对当前场景真正有用的维度：

- 时间组织：完整时间、压缩、交叉、重复、断裂、延迟。
- 摄影机参与：静止观察、响应人物、主动揭示、身体化或主观失衡。
- 视觉距离：空间、关系、身体、面孔、细节的使用倾向。
- 空间策略：先建立、行动中显露、有限主观、遮挡、前后景或图形化。
- 表演距离：面部、身体、群像、调度、背影、缺席或非表演性观察。
- 构图与透视：对称、偏置、中心、负空间、纵深、压缩、广角贴近等。
- 光线与色彩：光源逻辑、光比、曝光、色温、色彩重心和变化方式。
- 声音：环境持续、画外空间、主观过滤、音乐进入方式、声画错位。
- 剪辑连接：动作、视线、图形、声音、情绪、观念或长时间停留。

最终只保留三至六条会改变本场镜头的指令，并增加一至三条误用警告。

## 2. 风格指令模板

```text
场景适配：该参考帮助解决当前场景的什么问题。
时间与剪辑：时间如何流动，切点如何产生。
摄影机：摄影机保持什么距离、参与度和运动逻辑。
空间与调度：空间如何显露，人物关系如何被组织。
光线与色彩：光源、曝光和色彩如何服务当前戏剧。
声音：画内、画外和主观声音如何工作。
避免：最容易表面化、机械化或损害来源的做法。
```

不要把所有维度都填满。与当前场景无关的项可以省略。

## 3. 风格轴

可用以下开放式轴帮助描述，但不要求闭合枚举：

- 克制 ↔ 强介入
- 客观 ↔ 主观
- 空间清晰 ↔ 信息受限
- 纵深 ↔ 压缩
- 群像 ↔ 单一人物贴近
- 完整时间 ↔ 高度压缩
- 稳定构图 ↔ 持续重组
- 声音写实 ↔ 主观化
- 光源自然化 ↔ 造型化
- 连续剪辑 ↔ 断裂／蒙太奇

风格轴是讨论工具，不是评分系统，也不应生成配额。

## 4. 名导演参考的使用边界

可以把用户指定的参考转译为高层特征，例如：

- 精确、克制、低调的摄影机响应。
- 通过空间层次和调度揭示社会关系。
- 用声音、尺度和负空间建立压迫。
- 让演员在完整时间和共享构图中完成关系变化。
- 通过交叉时间、观念连接或图形蒙太奇组织信息。
- 使用主观听觉、失焦、跳切或时间断裂表现心理状态。

不要声称逐镜复制某位创作者，也不要把复杂风格缩成：

- 对称构图
- 慢推
- 冷色调
- 手持
- 大量特写
- 低机位
- 长镜头

这些只是工具，必须结合场景任务、Blocking、视点、声音和剪辑逻辑。

## 5. 用户未指定风格

默认从剧本内部生长风格：

1. 识别场景任务和观众位置。
2. 选择最能保护人物行为、空间和信息的摄影策略。
3. 建立场级一致性，但允许转折处改变。
4. 不展示名导演候选，不要求额外确认。

只有当两个方案在视点、时间、空间或声音上都成立且差异会显著改变作品时，才简要提供两个导演方案供用户选择。不要为了流程固定生成三项。

## 6. 风格一致性

一致性来自：

- 相同的观看伦理：观众被允许看什么、不被允许看什么。
- 稳定的摄影机参与程度。
- 可辨认的空间和透视处理。
- 对表演、声音和剪辑时间的一贯态度。
- 转折处有意义的例外。

一致性不来自每镜使用同样角度、焦段、运动、色彩或句式。相同可以成立，变化也可以成立；都需要服务场景。

## 7. 风格复核

- 当前风格是否解决了场景问题，还是只提供表面标签？
- 摄影、调度、剪辑、声音和光线是否指向同一种观看体验？
- 是否为了像参考而改变了来源事实、人物行为或场景节奏？
- 是否把一个工具过度复制到所有镜头？
- 风格例外是否对应真正的戏剧转折？
