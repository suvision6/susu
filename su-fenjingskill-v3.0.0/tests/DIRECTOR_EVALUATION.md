# Director Evaluation Suite｜导演型分镜人工测试

本套测试用于判断 Skill 是否真的“用镜头思考”。它不以字段通过率为主要标准，也不要求所有案例采用相同镜头数量。

## 1. 评分方法

每项按 `0 / 1 / 2` 评分：

- `0`：缺失、机械、与剧本冲突或只在文字上声称成立。
- `1`：基本成立，但存在模板、重复覆盖或执行不清。
- `2`：清楚、具体、可拍，并直接服务当前戏剧任务。

### 核心维度

| 维度 | 2 分标准 |
| --- | --- |
| 来源保护 | 事实、因果、人物关系和逐字对白无改写、无遗漏。 |
| 场景任务 | 明确开始状态、人物目标、阻力、转折和结束变化。 |
| Blocking | 走位来自人物行为和权力关系，不是为了迁就机位。 |
| 空间与方向 | 必须知道的锚点、视线、行动方向清楚；未知为有意隐藏。 |
| 观众位置／POV | 能说明观众贴近谁、观察谁、何时转移以及为何。 |
| 镜头动机 | 每镜通过删除测试；删掉后会损失明确的信息、关系、情绪、空间、主观或节奏价值。 |
| 摄影选择 | 景别、角度、机位、透视、构图、焦点和光线服务当前戏剧变化。 |
| 摄影机运动 | 运动有触发、路径、停止条件和相对固定观看的收益；固定也有理由。 |
| 对白与表演 | 不机械拍说话者；抽象情绪转为可观察、可表演的行为。 |
| 声音与画外空间 | 声源、距离、方向、静默、环境声和声音桥参与叙事。 |
| 剪辑连接 | cut／hold／reframe 改变观看；前后镜存在动作、视线、声音、图形、情绪或观念连接。 |
| 节奏与时长 | 时长容纳同步动作、顺序动作、反应、沉默和信息落点。 |
| 连续性与破坏 | 关系可读；越轴、跳切或方向破坏有明确观众效果和重新定向方案。 |
| 优雅降级 | 缺资料时继续交付可用方案，假设可逆且不制造新剧情事实。 |

### 通过条件

- 来源保护不得为 `0`。
- 镜头动机、Blocking、观众位置、摄影选择、剪辑连接不得为 `0`。
- 总平均分建议不低于 `1.5`。
- 任一镜头无法回答“为什么存在、为什么从这里看、为什么在这里结束”时，应重做或删除。

## 2. 案例 A｜双人对白中的权力转移

### 输入

```text
内景·办公室·夜
经理把辞职信推回给阿宁。
经理：你再想一晚。
阿宁没有接。
阿宁：我已经想了三年。
```

### 重点观察

- 不应自动生成“经理近景—阿宁近景”的机械反打。
- 辞职信、两人手部距离和“没有接”必须成为 Blocking 与关系设计的一部分。
- 第二句台词的画面所有权可以属于经理的反应、两人共享构图或阿宁；必须说明选择收益。
- 转折发生在“没有接”还是“三年”落下，应有清楚判断。

### 常见失败

- 每句一镜，只写“突出情绪”。
- 插入辞职信但删掉后没有信息损失。
- 阿宁突然站起、转身或流泪，来源没有依据。

## 3. 案例 B｜四人饭桌与秘密泄露

### 输入

```text
内景·餐厅·晚
四人吃饭。
母亲给弟弟夹菜。
姐姐：我今天看见爸爸了。
父亲停下筷子。
弟弟仍低头吃饭。
```

### 重点观察

- 先建立桌面几何、人物座位、视线和前后景关系。
- 群像可以通过共享构图、深焦、遮挡或镜内重构完成，不应默认轮流近景。
- “父亲停下筷子”和“弟弟仍低头”是两个不同观看价值：一个承受秘密，一个制造信息不对称。
- 夹菜动作和筷子声可成为声音节奏与切点触发。

### 常见失败

- 未建立座位就开始反打，视线不可读。
- 只拍说话的姐姐，错过父亲和弟弟的同时反应。
- 为了覆盖给四人各一个无动机特写。

## 4. 案例 C｜动作场景与方向压力

### 输入

```text
外景·地下停车场·夜
周野冲出电梯，向出口跑。
身后的卷闸门开始下降。
他滑过门下，背包被门夹住。
脚步声从黑暗里逼近。
```

### 重点观察

- 出口、卷闸门、人物行动方向和黑暗声源必须形成可读拓扑。
- 动作切应保护速度、重量和空间因果，而不是把每一步拆成插镜。
- 背包被夹是动作结果与节奏转折，必须有足够时长和声音设计。
- 脚步声可以在声源未出现前改变观看位置或焦点。

### 常见失败

- 前后镜人物奔跑方向反转且无重新建立。
- 用大量 0.5 秒镜制造“紧张”，但看不清门与出口关系。
- 卷闸门下降、滑行、背包被夹在物理上无法连续。

## 5. 案例 D｜画外威胁与延迟揭示

### 输入

```text
内景·儿童房·凌晨
女孩坐在床上。
衣柜里传来一次轻响。
她看向衣柜。
门外的父亲说：睡了吗？
女孩没有回答。
```

### 重点观察

- 观众何时知道衣柜、门和女孩的相对位置，应由悬疑策略决定。
- 衣柜轻响与父亲画外声来自不同方向，声音空间必须可辨。
- 可以延迟揭示衣柜内部，但不能让空间完全失去可读性。
- “没有回答”的时间长度和画面所有权比追加表情更重要。

### 常见失败

- 每个声源都立即切过去，消除画外空间。
- 衣柜声、门外声没有方向和距离。
- 以“女孩害怕”替代可见表演和停顿。

## 6. 案例 E｜长镜是否成立

### 输入

```text
内景·医院走廊·日
护士推着空病床经过。
林妍从手术室出来，看见走廊尽头的母亲。
她走过去，却在两步之外停下。
母亲抬手，最终没有抱她。
```

### 重点观察

- 先设计人物路径、病床遮挡、走廊纵深和两人最终距离。
- 可以采用长镜，也可以切镜；必须比较哪一种更保护犹豫、距离和未完成拥抱。
- 长镜需说明摄影机路径、焦点交接、遮挡、速度和停止画面。
- 若拆镜，切点必须对应观看或关系变化，不是为了景别丰富。

### 常见失败

- 因“情绪戏适合长镜”直接采用长镜，但没有镜内重构。
- 摄影机穿越病床或演员路径，物理不可拍。
- 母亲抬手前过早切特写，破坏距离的意义。

## 7. 案例 F｜信息缺失与优雅降级

### 输入

```text
一个女人在陌生房间醒来，听见有人叫她的名字。她发现门打不开。
```

### 重点观察

- 应以 `concept_board` 或 `locked_fragment` 继续工作，而不是拒绝。
- 可建立最小房间拓扑和暂定声源方向，并清楚标记假设。
- 不得擅自决定叫她名字的人是谁、她为什么被关、房间属于谁。
- 即使 XLSX、slug、场号或 VO/O.S. 不明确，也应交付导演摘要与六列草案。

### 常见失败

- 因没有完整剧本、角色名或场号停止。
- 为补齐信息编造绑架者、窗户、武器或过去经历。
- 假设散落在画面正文中，没有与来源事实分开。

## 8. 回归测试原则

每次新增规则前，用以上案例检查：

1. 新规则是否让所有案例更像导演设计，而不是更像填表。
2. 新规则是否只解决反复出现的通用失败，而不是单个项目偏好。
3. 新规则是否会让某个小歧义阻断其他可完成部分。
4. 新规则是否能被少量高权重语言表达；若需大量例外，优先删除或后置。
5. 后端能否确定判断；不能确定的内容应进入人工复核而非 FAIL。
