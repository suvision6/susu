# Chinese Context Language｜中文语境执行规范

本文件负责中文来源、对白、自然执行文字、可播性和交付表面，不决定镜头数量、方法或切点。

## 1. 中文来源保持

- 保留简繁体、全角标点、专名、称谓、语气词、叠词、方言词和中英文混排。
- `……`、`——`、`！`、`？`、`；` 与停顿标记属于表演节奏，不擅自替换或删减。
- 载体格式只能在可证明不是正文时移除；锁定来源不得重写内容。
- 每个非空来源行先进入 exact ledger，行中否定同样必须识别。

## 2. 角色标签与实际口播

来源可写：

```text
苏绾（小声试探）：那世子妃初试我到底过没过？
```

正式 `dialogue_lines[].text` 只登记：

```text
那世子妃初试我到底过没过？
```

角色名、冒号和括号表演说明不得进入实际口播。以下为硬错误：

- 把角色标签写入对白 text；
- 把括号说明当成说出的文字；
- 改写全角标点、语气词、称谓或人名；
- 为“更顺”而删减原文。

## 3. 中文对白可播性

Gate 0 先确认本项目的中文每秒字数、强标点停顿和弱标点停顿。该数值来自用户选择或本项目试读，不按“短剧／电影”名称暗中写死。正式 timing plan 从逐字 text 重算 dialogue seconds，再与动作、运镜、声音和反应按 parallel／sequential 时间块组合。

宽松物理下限继续保留，只用于阻断明显塞不下的中文口播；Gate 0 字速用于本项目的可复验估算，两者都不成为固定切镜节奏。

当前自动下限主要覆盖汉字；数字、拉丁字母、假名、韩文或混合语言仍需人工复核，不得把中文算法冒充通用多语言语速模型。

## 4. 中文第五列

XLSX 第五列必须从 camera、shot_flow 与对白索引确定性投影，并使用自然、连续、可拍的中文：

1. 可见初态与机位；
2. 人物动作、表演和空间关系；
3. 对白、声音、焦点或摄影机变化；
4. 运动触发、路径、速度和停止条件；
5. 可见／可听结束状态及剪辑出口。

固定表面为 `【角度，景别，运镜】` 加一个 `【画面内容】`自然段。逐字对白显示角色名，不显示 D/F/Gate/Alignment/hash 等内部 ID。避免后台分段、空值、字段拼接、空泛目的和抽象表演词。shot_flow 所引用的可见事实变化而第五列不变，或第五列与 camera/flow 矛盾，均为硬失败；未被 flow 选择的后台审计字段不要求进入 XLSX。

第五列减冗不使用统一字数上限，而检查重复来源：机位只写位置与朝向，不复述摄影头；构图只写空间排列，不复述 blocking；普通不变的焦点、环境声和结束状态保留在后台，不跨镜重复进入 shot_flow；同镜两个 flow owner 不得包含同一段事件正文。上述问题触发确定性阻断，不能等到人工渲染后才发现。

## 5. 中文摄影与声音表达

- 使用专业中文表达景别、角度、机位、构图、透视、焦点、光线、运镜、调度和声画关系。
- 景别使用固定专业词表，不把“紧中景”等口语化组合写入正式 camera 或 XLSX。
- “推、拉、摇、移、跟、升降、环绕、手持、固定”必须落到当前动作触发与停止条件。
- 声音区分现场对白、画外、旁白和介质声；画面所有权不得改变来源声音身份。
- 表演写视线、呼吸、重心、步速、手部、距离、停顿和声音力度等可观察行为。

## 6. 备注

- 默认空。
- 只写会改变正式镜头决定的真实待确认项，或已有戏剧理由与重新定向方式的连续性例外。
- 普通非空备注触发人工语义复核，不因某个自然语言关键词自动阻断。
- 本 Skill 不负责独立的现场筹备管理台账；相关信息应在正式六列合同之外处理。

## 7. 中文交付复核

1. locked text 逐字逐标点；
2. 实际口播不含角色标签和括号说明；
3. 对白片段按镜头顺序回放后与来源完全一致；
4. 中文口播具备最低可播性，且 timing plan 使用 Gate 0 已确认速度重算；
5. 第五列是与 camera/shot_flow 同源的连续中文前端投影；
6. notes 只承载真正待确认或连续性例外；
7. Markdown 与 XLSX 表头、换行和中文字体可读；
8. 机器文件名继续使用 ASCII slug。
