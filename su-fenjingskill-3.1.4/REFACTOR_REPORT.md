# 3.1.4 格式、对白剪辑与时长模型修复摘要

3.1.4 继承 3.1.3 的前后端分离和摄影语法，修复拆镜前格式、遗漏切点、结构化镜长，以及真实 EP02 回归发现的第五列重复来源与非规范景别转写。正式交付仍为四文件、两张 XLSX 工作表和固定六列。

| 问题 | 3.1.4 处理 |
| --- | --- |
| 后台 execution_text 被原样复制进 XLSX | 新增独立 XLSX renderer，仅输出摄影三要素和单段画面内容 |
| 镜内动作、对白、声音和运镜缺少时间顺序 | 新增受限引用的有序 shot_flow，不保存第二份自由正文 |
| Gate 2 切点证明四段式且在终稿重复 | 收敛为 trigger + editorial_gain，只在 workspace 保存一次 |
| edit、motivation 重复切点理由 | 移除 edit.reason 与 motivation.cut_or_hold_reason |
| XLSX 第二张表未完整 parity | 校验十个全剧导演设计维度及自然语言待确认项 |
| warning 误把无假设项目降级 | READY_WITH_ASSUMPTIONS 只由真实开放假设触发 |
| 3.1.2 无法直接满足新 flow | 显式迁移为新目录 draft，所有 Gate 与 Alignment 重新确认 |
| 关系戏被模板化为全程双人／群像 | Gate 2 每个单元必填 `viewing_design`，先锁定画面所有权、可见／画外主体和读取尺度 |
| 平视、固定与横移成为默认答案 | 正式镜头新增 `viewpoint`、`framing_mode`、主体层级及镜头特定景别／角度理由 |
| “保护完整过程”被误解为人物始终同框 | 完整过程与共享构图解耦；倾听者单人、过肩、细节、主观和空间构图都由当前观看收益决定 |
| 类别轮换冒充摄影设计 | 不设类别配额；极端同质方案需具体 `uniformity_intent`，复制理由则以 `CAMERA_DECISION_TEMPLATE_COLLAPSE` 阻断 |
| 拆镜前不知道成片节奏和画幅 | 新增 Gate 0，确认节奏预设、目标时长、画幅、方向、对白速度和覆盖倾向 |
| validator 只能检查已有切点，不能发现漏切 | 新增逐句 `dialogue_edit_plan`，每个来源对白都必须决定 establish／cut／hold／reframe |
| O.S. 留镜成为新模板 | 同一 unit 继续留镜必须逐句给出新的可见发展，否则触发 `MISSED_DIALOGUE_VIEW_CHANGE` |
| 9:16 等画幅只在导出时处理 | viewing 与 camera 增加 frame axis 和画幅应用理由；横移不禁用，但必须说明窄画框收益 |
| 镜长由自由文字估计 | 新增 timing blocks；并行取最长、顺序相加，对白按 Gate 0 速度重算，最终镜长必须一致 |
| “按类型调整语速”仍可被任意解释 | 新增 `su-dialogue-pace/1.0`，四类片型具有固定区间、默认值与停顿范围；擅改区间阻断 |
| 特殊人物状态需要越出类型范围 | pace override 必须绑定 scene／character／dialogue scope，并给出具体可表演理由 |
| 字幕 CPS 被误用为口播速度 | rate basis 固定为排除停顿的 articulation rate；字幕阅读速度明确留给下游 |
| parity 通过但第五列仍重复机位、构图、焦点、环境或出口 | 新增投影来源减冗；同镜字段互相包含、机位复述摄影头、模板焦点和同场重复可选项均阻断 |
| “紧中景”等非专业景别进入正式输出 | 固定规范中文景别词表；非规范词触发 `SHOT_SIZE_TERM_NONSTANDARD`，迁移草稿不猜替换 |

3.1.4 不以节奏预设生成固定切镜秒数，也不恢复强制正反打、镜头数量配额、景别配额或自由双写。预设只改变审查敏感度；具体切点仍由当前对白、动作、关系和信息变化决定。

风险、安全和治理内容不进入创作流程与四文件；来源、对白、结构一致、原子构建与版本回滚所需的技术检查继续保留。

真实 EP02 已从锁定原剧本重新执行并发现上述前端质量缺口；修复后必须再次以同一来源重建验证，不继承任何旧拓扑。
