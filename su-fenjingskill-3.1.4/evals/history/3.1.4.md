# 3.1.4 Evaluation History｜projection-quality-02

## Objective

- Add a pre-topology Gate 0 for rhythm profile, target runtime, aspect ratio, orientation, dialogue pace and coverage bias.
- Detect missed picture changes inside dialogue instead of validating only boundaries that already exist.
- Make shot duration reproducible from ordered and parallel timing blocks aligned to shot_flow.
- Bind every non-custom format profile to fixed su-dialogue-pace/1.0 min/max/default values and scoped overrides.
- Let aspect ratio influence composition and movement without introducing category quotas or hard movement bans.
- Turn the real EP02 finding “parity passed but the fifth column was still too dense” into deterministic redundant-source checks.
- Restrict formal Chinese shot-size wording to a canonical professional vocabulary and reject “紧中景”.

## Required evidence

- Gate 0 content hash and approval event participate in the invalidation chain.
- Every source dialogue ID appears exactly once in dialogue_edit_plan and every picture-step text span is verbatim.
- Static repeated O.S. holds fail; evolving listener holds remain legal.
- 9:16 horizontal movement remains legal with a shot-specific aspect-ratio reason.
- Timing blocks cover shot_flow, recompute dialogue from confirmed pace, and equal the final shot duration.
- A timing block can reference only BASE or a scene/character/dialogue override whose scope actually matches that block.
- XLSX remains two sheets and six columns; only the subtitle adds natural-language format information.
- 3.1.3 migration is non-overwriting, schema-valid and unresolved rather than guessed.
- Camera setup cannot repeat header terms; composition and flow owners cannot restate the same event; generic focus and repeated optional scene clauses fail.
- Canonical shot sizes and `中景→近景` pass, while non-standard aliases produce `SHOT_SIZE_TERM_NONSTANDARD`.

## Boundaries

- Rhythm profiles are directing biases, not fixed cut intervals or shot-count quotas.
- Dialogue pace numbers are explicit project facts confirmed in Gate 0; no hidden global characters-per-second default is used.
- Historical 3.1.3 installation and GitHub release remain unchanged until separate 3.1.4 installation and publication authorization.
