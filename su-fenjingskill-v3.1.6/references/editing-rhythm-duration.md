# Editing, Rhythm & Duration｜剪辑、节奏与时长

本文件处理镜头之间的关系。剪辑不是对文本的分段，而是对观看、时间、信息、动作、声音和情绪的组织。

## 0. Gate 0 节奏预设

拆镜前先选择一种节奏预设，并确认目标总时长、画幅和对白速度：

- `short_drama_under_10m`：十分钟以内短剧。对发言权、反应权、信息权、包袱和反转的变化保持较高切点敏感度；允许密集切换，但每刀仍需具体观看收益。
- `platform_series_episode`：平台长剧集。以剧情节拍、关系变化和信息落点为主，允许完整对白过程与反应余波。
- `short_film_3_20m`：3–20 分钟短片。作者时间模型优先，可极密或极疏；必须明确本片时间感和观看距离。
- `feature_film`：长片电影。目标时长独立填写；单场密度服从全片结构，不设固定切点或镜长。
- `custom`：用户明确给出自定义节奏逻辑。

预设不规定平均镜长、每分钟镜头数或每句反打。它只改变哪些变化必须被主动审查，以及继续不切需要证明的内容。

基础语速不得自由填写，必须使用 [su-dialogue-pace/1.0](dialogue-pace-standard.md)：

| 节奏预设 | 固定基础区间 | 默认值 |
| --- | ---: | ---: |
| 十分钟以内短剧 | 4.3–5.5 字/秒 | 4.8 |
| 平台长剧集 | 3.3–4.3 字/秒 | 3.8 |
| 3–20分钟短片 | 2.3–3.3 字/秒 | 2.8 |
| 长片电影 | 2.7–3.7 字/秒 | 3.2 |

Gate 0 必须展示区间与最终选值。没有额外依据时可以提出默认值，但仍需用户确认；越界必须建立有 scope 和具体表演理由的 pace override。

## 1. 先判断变化，再选择切或不切

对相邻观看状态选择：

- **cut**：瞬间改变观众位置、距离、信息、时间、空间或情绪。
- **hold**：保持构图和观看关系，让表演、压力、等待、声音或空间完整发生。
- **reframe**：不切镜，通过人物调度、摄影机、焦点、景别或构图变化重新组织注意力。

没有任何模式是默认答案。每个边界回答：

1. 当前观看已经完成了什么？
2. 下一刻需要新增、失去或重新组织什么？
3. 切、留、镜内重构中，哪一种最准确地改变观众体验？

## 2. 合理切点

常见切点包括：

- **动作触发**：动作开始、穿过、接触、失败、停止或产生结果。
- **视线触发**：人物看向目标，观众需要看到、拒绝看到或延迟看到目标。
- **信息落点**：一句话、物件、声音或动作改变理解。
- **反应触发**：观众需要从行为转向承受行为的人。
- **关系变化**：人物靠近、分离、越界、结盟或权力倒转。
- **声音触发**：声源出现、消失、改变距离、先行进入下一场或把注意力拉向画外。
- **节奏触发**：突然加速、停顿、断裂、重复或释放。
- **时间／空间跳跃**：省略过程、改变地点或进入记忆、梦境、想象。

“台词说完了”“换人说话”“动作结束了”只有在它们同时改变观看时才成立。

## 3. 合理停留

停留可以保护：

- 说话之后的沉默和身体余波。
- 倾听者受到声音作用的过程。
- 人物在同一空间中的权力变化。
- 真实时间、尴尬、等待、劳动、仪式或无力感。
- 画外信息进入静止画面的压力。
- 观众自主寻找画面中多层信息的时间。

停留过久的判断不是秒数，而是镜头是否仍在变化：信息、身体、关系、声音、焦点、空间或观众预期是否继续发展。

## 4. 镜内重构

reframe 可通过：

- 人物进入、离开、交叉、靠近或遮挡。
- 摄影机推进、拉出、横移、摇摄、升降或绕行。
- 焦点从一层转向另一层。
- 光线、门窗、镜面、屏幕或环境变化。
- 前后景动作改变视觉重心。
- 同一空间内的景别变化。

镜内重构必须让观众清楚感到观看关系发生变化。没有实际变化的“微调构图”不应被当作新的导演段落。

## 5. 镜头连接

寻找前后镜之间的主动关系：

- **动作连接**：动作在切点前后延续、完成或被打断。
- **视线连接**：看与被看、期待与目标、错误视线与真实对象。
- **图形连接**：形状、方向、尺度、位置、光暗或运动轨迹相呼应。
- **声音连接**：声音先行、延续、突然消失或改变空间属性。
- **情绪连接**：从压抑到爆发、从动作到余波、从亲近到疏离。
- **观念连接**：两个画面在意义上碰撞、类比、反讽或形成蒙太奇。
- **空间连接**：入口、出口、移动方向、遮挡物或共同声源连接不同位置。

转场不是预设特效。硬切、叠化、淡入淡出、声音桥、动作匹配、图形匹配或跳切都应来自场景关系。

## 6. 节奏设计

先设计场级节奏曲线，再估计单镜时长：

- **建立**：让观众进入空间、关系或主观状态。
- **推进**：信息和行动持续积累。
- **压缩**：省略过程，提高密度或制造不可逆势能。
- **蓄压**：镜长增加、切点延迟、声音或空间持续施压。
- **断裂**：突然切换距离、方向、声音或时间。
- **释放**：让动作、情绪或信息落地。
- **余波**：不急于离开，让结果作用在人物和观众身上。

场景不必包含全部阶段。重复、循环、稳定观察、突然中断或持续高压都可以是完整节奏策略。

## 7. 时长估计

`target_runtime_seconds` 是逐镜测量完成后的核对目标，不是时长分配器。禁止先把目标总时长拆成每镜停留值，再用这些值覆盖对白、动作、摄影机或反应的真实执行时间。

### 结构化时间块

```text
parallel 时间块 = 对白、动作、摄影机、声音、反应、停留中的最长者
sequential 时间块 = 上述分量相加
镜头时长 = 所有时间块按顺序相加
```

每镜必须保存 `timing_plan`：

- `blocks[]` 用 `flow_start_index / flow_end_index` 无缝、无重叠覆盖全部 `shot_flow`；
- `mode` 明确是 `parallel` 还是 `sequential`；
- 分量包括 dialogue、action、camera、sound、reaction、hold；
- `computed_seconds` 必须按 mode 重算；
- `computed_duration_seconds` 必须等于全部块之和，并与 `duration_seconds` 一致；时间分量可以是小数，但正式合计必须落在整数秒；
- `confidence` 只说明估算可靠度，不改变计算。

自由文字 `duration_basis` 只解释表演和物理依据，不能替代 timing blocks。

### 整秒交付

- 正式 `duration_seconds` 只能是大于等于 1 的整数秒。
- 不把已经测出的 2.6 秒直接改写为 3 秒；应回到镜内事件，明确哪一个可执行动作、反应、声音、运镜或独立停留使时间边界成为 3 秒。
- timing block 内的对白、动作、声音、反应等分量仍可保留小数，以保存测量依据；只有全部 blocks 的真实合计必须等于正式整数镜长。
- 目标总时长仍是事后核对项，不能拿总时长差额为各镜补齐整数。

### 独立停留

`hold_seconds` 只表示没有对白、动作、摄影机运动或反应正在占用时间的独立静默、等待、凝视、停滞或余波。摄影机没有切并不自动产生 hold 分量。

- 含 dialogue、action、camera 或 reaction 正值的 block，`hold_seconds` 必须为 0；
- 对白或动作后的停顿必须另建后续 block；
- 正值 hold block 不得覆盖 dialogue_segment、blocking、movement 或 state_update；
- 它必须覆盖 performance、focus、ambience 或 edit_exit 中至少一项可支持停留的 flow；
- `duration_basis` 或 timing basis 必须说明可观察起点、结束条件和当前戏剧功能。

机器只阻断活动事件与停留冲突、没有 flow 证据的停留或分量与 owner 不一致；不因停留很长而自动失败。

### 对白

- 根据语言、人物状态、语速、停顿和表演估计，不使用全局固定字符率决定导演节奏。
- Gate 0 必须明确 standard、rate basis、固定区间、默认值、最终选值和强／弱标点停顿；validator 拒绝擅改 profile 区间。
- validator 从逐字对白重新计数并计算 dialogue seconds；声明值与重算值不一致时硬失败。
- 每个 timing block 的 `pace_ref` 必须是 `BASE` 或 scope 匹配的有效 `POxxx` override，禁止另写一套任意字速。
- 台词可以与动作、走位、反应和摄影机运动并行，避免机械相加。
- 括号表演说明不计入口播文字，但需要计入动作或停顿。

### 动作

动作时长考虑：

- 起始姿态和准备。
- 实际路径、阻力、重量和物理惯性。
- 角色是否犹豫、隐藏、匆忙、受伤或被打断。
- 摄影机是否需要等待动作进入构图或完成焦点变化。
- 动作结果是否需要被看见和理解。

### 反应与沉默

只有具有戏剧功能的停顿才加入：

- 人物处理信息。
- 权力暂时悬置。
- 观众等待目标出现。
- 声音、空间或物件继续作用。
- 反应被压抑、错过或拒绝展示。

不要为“高级感”给所有台词后统一加停顿。

## 8. 超短镜

1–2 秒是超短镜，只在单一事件能在该窗口内完整读取时使用，例如：

- 瞬时信息、冲击、动作接点、闪回、主观碎片或节奏断裂。
- 图形、声音或观念蒙太奇。
- 高速动作中的必要方向或危险信息。

每个超短镜的 `duration_basis` 必须同时说明：

1. 可观察起点；
2. 可观察结束条件；
3. 为什么短促本身服务于瞬时信息、动作接点、冲击、断裂、主观碎片或其他当前场景功能。

缺少这三项中的任一项，触发 `ULTRA_SHORT_SHOT_EVIDENCE_MISSING`。满足证据后，数字本身不自动失败，但仍生成 `ULTRA_SHORT_SHOT_REVIEW_REQUIRED`；同场出现连续超短镜段时生成 `ULTRA_SHORT_SHOT_CLUSTER_REVIEW_REQUIRED`。审阅需确认：

- 信息是否来得及读取。
- 对白是否被错误压入。
- 镜头是否只是重复上一镜。
- 短促是否符合整场节奏，而非统计需要。

这些诊断不设置数量、比例或连续段长度配额。超短镜应当少见，是因为每一镜都必须有不可由正常镜长更准确完成的短促功能，而不是因为校验器规定固定上限。

## 9. 长镜与长时间镜头

长镜头成立时，镜内应持续发生观看变化：

- 人物调度改变关系和画面层次。
- 摄影机或焦点改变信息位置。
- 声音扩展画外空间或改变主观距离。
- 动作、表演、等待或环境过程需要完整时间。
- 不切本身使观众承担压力、尴尬、危险或无力。

长镜头设计至少说明：

- 起始观看状态。
- 镜内主要段落和转折。
- 注意力如何重新分配。
- 摄影机、演员、焦点和声音的执行路径。
- 为什么切开会损失当前价值。
- 镜内执行路径，以及为何不切仍能保持信息清楚。

长镜没有最低秒数。普通长时间固定镜也可以成立，只要持续的表演、声音或等待仍在产生意义，并由按真实顺序组织的 timing blocks 证明；不能用一个等于整镜时长的 hold 分量代替内部过程。

## 10. 对白剪辑

- 说话者变化不自动切镜。
- 看说话者：强调表达、权力、谎言、身体或语言细节。
- 看倾听者：让声音作用于对方，显示隐藏反应或权力承受。
- 看关系：共享构图、过肩、前后景和调度让交换发生在同一空间。
- 看物件／空间：让对白改变某个物件、空位、出口或画外威胁的意义。
- 拒绝反打：可以制造缺席、冷漠、制度感、悬念或观众不安。

同一句对白跨镜时，声音必须连续，文本不重不漏。Picture cut 的理由来自观看变化，不来自文本切片本身。

## 11. 动作剪辑

动作场面先保护：

- 谁在何处。
- 谁向哪里行动。
- 目标、阻力、危险和结果。
- 关键动作的因果关系。
- 主观体验与客观空间之间的切换。

可以采用：

- 宽镜保护空间与动作逻辑。
- 中近镜保护身体和决策。
- 细节镜强调关键接触、失败或信息。
- 主观、失焦、遮挡、跳切或断声制造身体体验。

不要用大量无方向近景替代动作设计。镜头数量不能弥补 blocking 和空间不清。

## 12. 剪辑复核

逐个切点及每个未切的对白节点做对比：

- 不切会发生什么？
- 切到当前画面获得什么？
- 切早一拍、晚一拍的效果有什么不同？
- 声音是否应该先于或晚于画面改变？
- 前后镜在视觉重心、方向、尺度和情绪上如何相遇？
- 当前切点是否只是覆盖习惯？

若无法说明变化，优先合并。若同镜承载后注意力不清或失去必要冲击，优先切开或重构。
