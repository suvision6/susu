# Performance Arc

本文件是情绪分析阶段、可见表演行为及其跨镜连续性的唯一规则源。

## 1. 双层表达

只有当表演行为会改变观看距离、节奏、焦点、镜内调度或剪切时才记录。相关镜头可以同时保留：

- `emotion_intent`：供导演和人工理解人物内部意图。
- `visible_behavior[]`：摄影机能直接观察的表演行为。

抽象情绪不能单独充当画面执行。只有表演方向会改变镜头观看时才建立该对象，并把它转成最少且足够、与具体演员和场景相符的可见行为；不要把微表情清单当作自动生成菜单。

## 2. 阶段只用于分析

允许阶段：

```text
qi | cheng | zhuan | shou |
qi_to_cheng | cheng_to_zhuan | zhuan_to_shou |
steady | existing_transition | not_applicable
```

- 起、承、转、收帮助分析，不是必须凑齐的模板。
- 原文只有稳定推进时使用 `steady`。
- 场景从既有状态进入已写明的新状态时可用 `existing_transition`。
- 不得为了完整四阶段增加原文不存在的刺激、升级、崩溃、决定或余波。
- 阶段是可选分析工具。镜头不需要为了完整结构填写阶段。

## 3. 可见行为设计

优先选择与当前事实、演员任务、时长、景别和调度匹配的高信号行为。行为可以来自视线、声音、呼吸、姿态、手部、重心、距离、停顿或动作节奏，但每次只选真正改变观感的部分。避免重复套用“微微皱眉”“眼神复杂”等泛化动作，也不要在短时间块堆叠无法完成的动作链。

## 4. 事实边界

- 行为必须服务已锁定情绪或动作事实，不得改变人物目标、关系、剧情结果、道具状态或空间位置。
- 与来源一致、不制造新剧情事实的可逆表演选择属于导演阐释；先写入 `performance.visible_behavior`，不得把它登记为 source fact 或用于 coverage evidence。
- 不可逆动作、道具操作或人物位移同时登记调度和连续性更新。
- 说话者的声音行为放在对白发生关系中；倾听者反应必须来自可见人物。
- 原文无情绪信息时，不创建新的情绪阶段；可记录 `not_applicable`。

## 5. 跨镜连续性

只为影响后镜的表演状态记录当前变化和供下一镜继承的结束状态。后镜继承前镜已经成立的握持、视线、姿态、重心与人物距离，除非有可见动作或连续性更新解释改变。

以下情况不得无依据重置：

- 松开后又重新握紧同一道具。
- 站立、坐姿或倒地状态跳变。
- 强烈反应立即恢复初始平静。
- 视线对象或人物距离改变。

## 6. 画面内容中的表演

最终镜头的【画面内容】段落负责承载可见表演。不要把 `visible_behavior[]` 机械搬运为第五列，而应根据 `shot_phases[]` 的真实顺序把行为自然写进初始画面、镜内变化和结束画面：

```text
当前环境 → 摄影机相对位置/朝向 → 画面可见内容 → 人物动作与表情 → 人物台词 → 人物状态
```

- 表情和动作要具体、可观察、可表演，避免“眼神复杂”“情绪涌动”等概括性描述。
- 同一人物在同镜内的动作—反应—停顿—台词应写成连续过程。
- 表演行为服务于来源事实和导演意图，不得编造新的剧情事实。
- 不要为通过校验堆叠微表情或不必要的身体细节。

## 7. Performance chains

只有连续动作、反应或台词确实可能被剪切破坏，而且自然语言“受保护过程”不足以表达时，才建立最小表演链：

```json
{
  "chain_id": "PC001",
  "scene_id": "SC001",
  "character": "A",
  "steps": [
    {"role": "action", "fact_ids": ["F003"]},
    {"role": "reaction", "fact_ids": ["F004"]},
    {"role": "dialogue", "fact_ids": ["F005"]}
  ]
}
```

- 链至少两个步骤，按来源 fact 顺序严格递增且不重复。
- `action` 只引用 action fact；`reaction` 引用 emotion 或承担反应的 action fact；`dialogue` 只引用 dialogue fact。
- action／emotion 的 performers 和 dialogue 的 speaker 必须包含或等于 `chain.character`。
- 整链优先落在同一规划单元。若切断，必须在对应 Gate 2 剪切点的 `broken_performance_chain_ids[]` 登记；不存在真实跨单元断点时不得虚报。
- 短反应、推荐插镜或景别变化不能单独成为断链理由。
- 当整链落在同一最终镜头时，其动作、反应、停顿与台词必须在同一权威【画面内容】段落中保持连续。结构化 blocking、performance 和 dialogue 只在确有机器追踪价值时保留，第五列不得逐字段重复拼接。

## 8. 机器校验边界

- `performance` 对象可省略；有非空 `emotion_intent` 时，`visible_behavior[]` 必须非空。
- `visible_behavior[]` 只接受非空、摄影机可观察且会影响观看组织的描述，按执行顺序排列。
- 未声明的表演链断点为 FAIL；合法声明只说明断点存在，不自动证明其导演价值。
- 已登记的同镜表演链不得在权威执行正文中被机械切碎；逐字对白缺失为 FAIL。
- 未使用阶段或缺少起/承/转/收不构成错误。
- 表演是否准确、克制、俗套或有导演价值属于人工审计。
