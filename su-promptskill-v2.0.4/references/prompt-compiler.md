# Prompt 编译器

编译器先建立模型中立事实链，再应用 Profile adapter。它只翻译，不重新导演。

## 每个 Cut 的事实边界

逐 Cut 消费对应源镜的场景、主体、动作、构图、摄影机、连续性、声音和原文对白。不得跨 Cut 借用事实，不得把缺失信息补成确定事实。已有可见表演优先，获批的最小情绪派生必须标明 provenance。

普通生成先把结构化事实编译成可读的连续阶段，而不是字段清单。每个 Cut
只选择一个来源支持的主要状态变化；构图、起始状态、摄影机、动作／表演、
对白和声音作为该变化的支撑信息自然组织。结构化字段拥有对应事实的唯一输出权；
`rendered_shot_description` 只补未被结构化字段覆盖的独有事实，不得整段复制。
比较时可以规范化空白和标点，最终文字仍逐字使用来源表达。
结构化起始状态与终态即使在运镜触发、停止或保持句中只缺少末尾标点，仍由结构化字段唯一输出；`机位设在`、`机位落在`、`机位以` 等摄影机句式不得进入场景行。

## Seedance 2.5

使用 `seedance-2.5-structured-zh-v1`，并完整遵循
[seedance-2-5-adapter.md](seedance-2-5-adapter.md)。结构标题只组织当前实际存在的
目标、素材、主体场景、镜头脚本、跨 Cut 声音与保持一致；不得输出未采用素材区块。

Seedance 2.5 正文顺序为“目标 → 按需素材职责 → 主体、关系与场景 → 镜头脚本
→ 固定声音与台词台账 → 保持一致”。不生成或注入画面风格提示词。无资产映射时
省略素材职责；`【声音与台词】` 始终存在。普通生成不得重复输出“构图：”
“画面内容：”等逐 Cut 字段外壳。

每个 Cut 使用 `Cut N｜时间段`；非整数或未知边界使用“顺序阶段”。对白、旁白、
环境声和音效优先写在对应 Cut 内，并在声音台账中登记适用 Cut、说话人或声源；
没有来源声音时固定写“本单元无来源明确提供的台词、旁白、环境声或音效”。
无 BGM、无字幕、禁言、禁口型和口型同步只有
来源或用户明确要求时才能写入。`【保持一致】` 必须是正文最后区块。

来源未提供直接 `audio`／`sound` 字段时，允许从来源 facts、镜头覆盖关系与明确的
背景音、撞击、低吼、震动、呼吸、脚步、雨声、风声、沉默或无声表述中恢复声音；
必须保留原意，不能补通用 Foley 或任务中不存在的音效。

可靠整数来源时间可写时间段。非整数来源时间只保留在机器时间线，正文用 `Cut 1`、`Cut 2` 或“第一阶段、第二阶段”；禁止四舍五入。只有请求目标时长时不得写数字时间段或“总时长”。

## Seedance 2.0 与 generic

兼容 Profile 保持原适配器行为和 Profile 上限。适配器可以改变格式与受支持表达，不能改变事实、源镜顺序、Cut 映射或对白。

## 任务特定要求

- `generate`：主体、事件、场景、镜头、声音齐全；多参考明确每个素材职责。
- `edit`：唯一母版、修改对象、目标数量、继承时间线和未修改范围闭包。
- 声音编辑：额外锁定未修改声音、口型时点与全部画面。
- `extend`：方向、边界状态、运动趋势、声音状态、单实例连续性；不改写原片。
- 首尾帧：使用精确职责句，不降级为普通参考。

## Prompt 纯净度

`prompt_text` 可直接提交，只包含创作指令。禁止出现：

- Model Profile、模型 ID 或能力说明；
- ratio、duration、resolution、output format 等请求参数；
- advisory、诊断、自检报告或分析过程；
- Markdown 代码围栏或外层解释；
- 裸 Asset ID、库存外标签；
- 编造对白或改写对白。

结构化 Prompt 的内部中文标题允许保留。
同一 Cut 内的场景、摄影机位置、start frame、end frame、对白和规范化事实句
不得重复；`PROMPT_REDUNDANCY_DETECTED` 属于阻断错误。
