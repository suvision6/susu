# Cut 链

每条源镜建立且只建立一个 Cut，保持来源顺序。Cut 是 Prompt 内部执行单元，不是新镜头。

## 机器时间线

保存来源精确时长和累计边界。未知保持未知，小数保留原值。Profile 目标时长不能反推
来源时间戳。未知时长源镜保持单镜。

## Prompt 表达

- 所有边界为可靠整数秒时，可使用数字时间段；
- 有小数边界时，使用有序 Cut/阶段，不写取整时间戳；
- 只有 API 目标时长时，使用无数字阶段，不写“总时长”。

Seedance 2.5 最多 Cut 1 到 Cut 10；Seedance 2.0 与 generic 最多 Cut 1 到 Cut 5。
超限由 `scene-global-dp-v1` 在全范围选择容量拆点，不丢镜、不合并 Cut，也不篡改语义兼容性。

## 连续性

相邻 Cut 只继承来源给出的边界状态、运动趋势、视线、道具和声音状态。不得为了顺滑补动作、
对白、镜头角度或事件。`boundary_state_match` 只能在来源边界文本确有对应时声明，脚本会复核。
