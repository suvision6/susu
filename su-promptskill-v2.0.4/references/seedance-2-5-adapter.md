# Seedance 2.5 Prompt Adapter

本文件只描述 `seedance-2.5-structured-zh-v1`。它依据官方教程、官方 Prompt 指南和 `sd25-pe 0.1.0` 的通用优化流程；不复制或依赖官方 Skill。

## 通用编译顺序

`Normalize -> Validate -> Route -> Compile -> Verify -> Deliver`

先锁定故事合同，再做两遍素材理解、逐边界合镜审阅、唯一主任务路由、结构化正文编译与自检。来源事实优先于素材推断。

## 素材治理

- 第一遍读取完整库存；第二遍只深读已匹配、冲突、关键帧和当前场景素材。
- 映射优先级：用户指定 > Prompt 描述 > 素材内容 > 文件名/元数据 > 上传顺序。
- 用户显式标签逐字保留，tag 在库存内唯一；Prompt 只能引用库存成员，不得出现裸 Asset ID。
- 同一素材可承担同一实体的多个兼容维度。跨实体复用必须由用户明确指定，或素材明确包含同一群体。
- 未映射库存只留在 Plan 审计中，不进入 Prompt，也不生成 `【未采用素材】`。
- 非核心素材不可访问时删除引用并提示；唯一母版、延长源或核心身份不可访问时局部阻断。

## Prompt 结构

`prompt_text` 只含可提交内容。允许结构化中文标题，不含模型名、参数、分析、advisory 或 Markdown 外层包装。

### 普通生成

按以下顺序输出可提交正文：

1. `【生成目标】`：一句话概述主体、地点和核心事件；
2. `【参考素材职责】`：仅当前单元确有映射素材时逐份写明；
3. `【主体、关系与场景】`：写清身份、数量、关系、道具与空间；
4. `【镜头脚本】`：逐 Cut 或有序阶段连续推进；
5. `【声音与台词】`：固定存在，逐项登记来源声音；无来源声音时明确写无；
6. `【保持一致】`：最后区块，只写有来源依据的贯穿约束。

每个 Cut 恰好选择一个来源支持的主要状态变化。起始状态、构图、摄影机、
次要动作、表演、对白和声音围绕该变化自然组织，不输出机械字段清单；整段
渲染描述只补独有事实。白模重渲染仍按 `generate` 路由。

### 多参考生成

按需使用：

- `【生成目标】`
- `【参考素材职责】`
- `【主体、关系与场景】`
- `【镜头脚本】`
- `【声音与台词】`
- `【保持一致】`

素材职责必须具体到实体和采用维度，不能只列标签。

素材职责不得自动增加映射中没有的身份锁定、面容锁定、排除项或负向约束。
对白和声音优先写在对应 Cut，并稳定写入声音台账；跨 Cut 时再追加连续性关系。无 BGM、
无字幕、禁言和口型规则都不是默认项。

### 编辑

必须有唯一母版，明确修改对象、目标数量、时间线继承以及未修改范围闭包。声音编辑还要锁定未修改声音、口型时点和全部画面。

### 延长

必须声明向前或向后、边界状态、运动趋势、声音状态和单实例连续性。只延长，不同时改写原片。

### 首帧与尾帧

使用精确职责句：`@tag作为首帧。`、`@tag作为尾帧。`，不得弱化成普通构图参考。

## 时间表达

- 只有来源或用户提供的可靠时长且边界能无损写成整数秒时，才使用数字时间段。
- 非整数时长保留在机器时间线，Prompt 使用顺序 Cut/阶段，不四舍五入。
- 只有 API 目标时长时使用无数字阶段；不写时间戳，也不写“总时长”。

## 自检

检查故事事实、实体、逐边界合镜审阅、素材职责、对白逐字性、说话人/音频绑定、任务单一性、官方五类 task routing、`content.role` 互斥规则、时间表达、参数隔离、未修改范围、每阶段一个主要状态变化、事实无重复和所有标签的库存成员关系。
