# 最小空间、可选参考与真实执行

## 1. 三种材料情况，是同一条工作流

纯文字、部分参考、足够参考都以采用分镜为基本依据。没有图片正常进入预演；有图只增强已指定维度，不另建none／partial／bound准入状态或逐格审批。

无图时，按[视觉方法](visual-development.md)形成最少临时轮廓和空间。部分参考时，仅相关角色或结构依图，其余照文字继续；不把一个人的参考复制给所有角色。不默认先制作定妆照、全景卡或三维模型。

用户没提供图片，与提供了但读不到不同。后者如实说明，不假称识别；先继续无关部分。在授权内采用临时安排时写明尚未匹配指定图；明确要求复刻或编辑的目标缺失，则只保留相关依赖，不能用自行设计冒充成功。缺生图工具是运行问题，不是必须补参考的问题。

## 2. 有图时，读取的是可观察的信息

| 图的用途 | 实际采用 | 不顺带采用 |
|---|---|---|
| 人物 | 足够辨识的脸型、发型、体型和约定服装轮廓 | 参考表情、头向、姿势、持有物、机位 |
| 场景 | 可见主要结构、必要固定物、通道、相互遮挡 | 全屋精确尺寸、照片背后空间、偶然路人、拍照机位 |
| 道具 | 形状、相对尺度、开合结构和非对称特征 | 当前持有者、动作完成时点 |
| 指定构图 | 主体尺度、观察方向、前后景及边界 | 新人物、新事件和冲突的动作 |
| 光影／画法 | 任务明确采用的方向、明暗与线条关系 | 照片级材质和无关装修 |

在实际调用里写明每张参考的采用维度。照片可只取辨识与结构，不能连同照片媒介、姿势或机位全部继承；用户明确给的是画法参考时才采用相应笔触，不再用“所有参考都不是风格参考”的绝对句。

只写实际看过的图中可见信息。只凭文件名、hash或角色名不能宣布已经识图。必要时放大相关区域；不必逐项描述全部装饰。黑白预演保留可证轮廓与必要表情，不能凭空加伤疤或徽记区分人。

若颜色是唯一辨识线索，保留原颜色文字；用预演明暗编码辅助时说明是阅读编码，不冒充原服装颜色。不因统一石墨把浅焦、侧逆光或阴影关系一律抹掉。

用户新修正优先于旧稿相应范围；参考与采用摄影真冲突时定位对象和影响，不以“更好看”裁决。参考镜像或非对称服装／道具需核对，不能为方便反打翻转图片。已生成图片只继承复核过的身份和结构，偶然缺陷不升级成来源事实。

## 3. 场级锚定与当前机位

纯文字、部分参考和有参考都先完成[三层锚定](anchors-and-continuity.md)：稳定核心身份、整场空间、带源镜时点的初态与更新。参考识别结果进入相应锚并随实际调用传入，不能因有图跳过锚定。稳定身份不含当前笑容／朝向／持物；位置变化及转身、起坐、交接只更新相关状态，不重置其余人和固定物。

三层锚写入原 `## 共用视觉依据` 的三级小节；本页已生效状态写入原“页面说明”，当格状态展开在正文。原脚本搬运现有上下文，不自动推理、筛选或计算调度。未来更新不提前生效，跨页或补画早期格均按来源时点而非生成次序取状态。

空间依赖只写本场所需，但跨页共用。

用现有共用依据表达三层关系：

**场景位置：**人物站坐、朝向、桌柱门窗、必要通道和物件状态。来自文字和参考的内容，与授权临时设计分开。没有精确尺寸就不造精确数字，也不强制做平面图。

**当前机位：**围绕哪两人或哪条行动路线，相机处于哪一侧、高度相对谁、看向哪里。使用可辨认参照，例如“桌子靠门一侧”；无门也可相对于人物关系定临时侧别，不为了命名轴线新增一扇门。

**格内结果：**谁在前景、肩属于谁、主体哪张脸／哪只手要读清、目光朝谁、哪些形体挡在哪里。相机参数名称不代替这个结果。

位置描述先区分人物的场景区域和画面重心。“受到全场注视”“九皇子”“权力中心”都不授权生成高台、王座或挪入主位。源稿已定在宾客席间，就沿用宾客席；真正的主位属于谁要独立保留。未给出的高差、中央通道或台阶不能伪装成原文事实；必要临时安排标明一次并继承。存在特别容易误画的排除关系时，用一句具体否定保护，而不是列大量通用禁令。

每格不必复述整屋，但应能从共用依据定位本机位。例如“从嘉宁肩后、位于嘉宁—皇子关系线靠通道一侧，看仍在宾客席边站立的皇子；嘉宁肩缘在画右前景，皇子朝她看，主位不入此框”。这只是条件明确后的句式，不为用户剧本预定座次或统一左右。单写“正面偏侧、沿同侧、不镜像”不能替代实际位置与画框。

世界位置不变，画面投影随相机变化。不能把“甲永远画左”作为身份规则，也不能因为前后图里门出现在不同画边就自动判几何改变；先核对机位。反打不等于镜像，镜面中实体和反射也不能混用。

两人交流用当前关系线；第三人介入、换位或共同望向物件后重判相关眼线，整场不是一条永久轴。摄影机明确连续越轴或源镜有意跳轴时，基准忠实保留并检查可读性；备选换轴侧要明确另案，不静默插入采用序列。只画运动头尾不证明中间路径可靠。

车辆按车头车尾、指定座位、驾驶侧定位，不默认左舵，也不在反打中交换驾驶者。门窗与镜面只在相关镜头处理，不把车辆／镜面栏目强加给普通对话。

## 4. 构图中的出现、可读与禁止揭示

主阅读对象需达到本镜所需的可读程度；关系轮廓只需身份与位置成立；关键动作部位和物件状态单独照顾。人物局部入画不等于整人必须清楚。

肩后近景中，前景人的肩和后脑可以简化；不能为认人把他转成正脸或推远改成双人中景。局部手部镜也不添加完整脸。前景面积、主体尺度、留白、焦点与遮挡属于摄影，不以低细节为由重排。

“当前没入画”与“剧情此时不能揭示”分开：同刻备选可纳入空间中已确定、允许揭示的对象；悬念对象不能因画外有声音就提前画出。群体同步反应可减少五官细节，但要有真实可见方向；声音信息不能充当画外目光已经被看见。

近景可留白背景，但影响这个机位的结构要保留轮廓。无法看见的动作不靠省略桌面或柱子处理；定位采用摄影问题，另给可比较方案。

## 5. 有效画幅与完整页面分别处理

默认每页三行三列九个矩形画面，从左到右、从上到下；净图内无编号、箭头、字幕、气泡和水印。剧情必要的物件文字按来源处理，生产定位默认由程序加在每格顶部框外标签带，详见[审阅与PDF](review-and-pdf.md)。完整九格不是九个Cut。

单格有效画幅继承源镜。9:16就按竖幅构图，16:9、4:3、2.39:1等使用相同方法，不为每个比例新增流程，也不默认同时生成多版。只有材料未给画幅时，沿已有项目条件或授权选定并说明。

同画幅时优先同方向3×3页面。外部必须横版承载竖幅时，在各外格内完整保留竖幅有效内容；边带是版面，不是缺格。不拉伸、不裁掉关键前景、不挪人物满足尺寸。混合画幅则每格保持自己的有效框。

按整页W×H、边距m_x/m_y、格缝g_x/g_y计算：

```text
w_cell = (W - 2*m_x - 2*g_x) / 3
h_cell = (H - 2*m_y - 2*g_y) / 3
```

同画幅若由单格w×h排版，整页宽为3w+2g_x+2m_x，高为3h+2g_y+2m_y。边距存在时，整页比例不一定精确等于单格；验证格内有效边界，不只看整页分辨率。像素取整不靠拉伸解决。裁出单格是裁真实有效区域，不凭裁切宣称获得原生高清。

## 6. 实际调用必须拿到完整依据

无参考调用＝画幅与低细节画法＋必要人物／空间（文字或临时选择）＋本页或本格的准确时点、机位与可见状态。有参考在此基础上附真实图片与用途，不伪造参考路径或用空白图作占位。

整页带齐九格；单格也带齐共用依据和必要接续。正文写“与格2同刻”时，该次独立输入必须包含格2相关状态或明确展开，不让模型猜未收到的另一格。不直接把主稿JSON路径当成已传入内容。

全范围使用`prepare_prompt_set.py`从保存主稿整理所有页面的完整Prompt与明确取帧映射；局部可继续用`prepare_image_request.py`整理当前页／格。两者不重写剧情、不生成图。输出不是任何供应商的API请求；Agent仍要读取其prompt，把实际附件按宿主支持的方式传入，核实调用后才能声称已使用参考。工具只查文件与搬运文字，不确认图片中是谁。

全页TXT、请求JSON里的prompt字段和完整阅读稿应当一致；实际调用不再手动压缩成另一版。当宿主要求结构化包装时，保存包装后的实际载荷或明确不能读取，不用整理文件哈希冒充模型已经收到。用户要求先看到全部Prompt时，不能仅给第一页样例或一个文件路径就继续出图。

单格输入中其余格只作为时间与关系上下文，不是额外绘画任务；目标仍是一格。工具自动搬运当前页，涉及跨页接续时由Agent附上相关状态或页面，不能把“与上一页相同”当成模型已知。整页与逐格两条路径保留用户已有有效方式，不未经配对试验断言哪种一定更稳。

宿主未暴露参数、无法读取某类素材或没有图像工具时，如实说明该项能力；不得伪造调用结果。修改旧图必须先读取真实目标，新建文字九格不需外部图片。Skill开发、解释或只要文字的任务不触发生图。

## 7. 看图、修复与预演结论

先看实际图中人物、手、物件、眼线和遮挡，再对照采用稿和共用空间。有图时增加指定参考属性核对；无图时检查本次临时设计的一致、辨识和几何自洽，不以不存在的照片相似度判错。

按基准及必要过程检查当前关系轴、跨页人物与持有状态；备选单独比较，不把它们混成正式剪辑。必要时放大关键格再判断面孔／接触点，整页缩略看不清不等于已经通过。

| 问题 | 修复位置 |
|---|---|
| 读错说者、时点或持有状态 | 回读采用稿，修相关计划与衍生图 |
| 图没遵守已清楚的肩背、方向或构图 | 修该格实际生成／编辑，复看关联邻格 |
| 指定参考读不到或局部空间不明 | 保留局部依赖，继续无关部分；不索取全套参考作为门槛 |
| 原机位要求与已知障碍矛盾 | 报告源镜冲突，备选独立保存，不暗改基准 |
| 装饰、材质不精细，但任务信息正确 | 不因“不漂亮”返工 |
| 擅加精细首饰、发丝、建筑纹样，或主体难辨、关键物件看不清 | 修画法与角色／物件表达，不能把漂亮或“九格齐全”当成合格 |

已生成但未通过的一页记为待修，不称最终完成。局部内容错可编辑单格；整套媒介/空间错先纠正共同输入，再选择修相关图或重新生成。不是所有画法错误都无限整页重画。必要时在源镜组范围内切换单格生成，其他格沿用已核对图；维持同一共用依据，避免拆开后身份和空间反而漂移。

修图使用真实目标，明确修改对象与保留范围。为了不影响其他八格，优先从真实有效画框提取目标格、修改后重新排版；其他格不进入这次生成。被改格仍须再看，受影响邻格再比较。相似度可以提示疑似重复，不能自动删除有效覆盖。

用户按约定批次统一审阅；Agent自查不等于导演确认。状态、版本与PDF方法见[审阅与PDF](review-and-pdf.md)，不另建逐页批准闸口。没有看过实际图就不写视觉通过，没有真实用户确认就不填已确认。

## 8. 交接保持来源与用途

源镜、时点、画面关系仍在主稿，编号、修图版本、选用与用户确认由现有产物清单派生和记录。完整净图不含标签；带号审阅版与PDF另行排版。只做计划时不登记不存在的PNG。

基准检验原方案；过程格不增Cut；备选未采纳不成为正式摄影。人物参考被采用不等于其机位被采用。正式改变导演摄影由导演职责更新，图像阶段只提出反馈与备选。

关键画面不是自动的严格首尾帧；已抬头/已抱匣不能替代动作开始状态。静态结果不证明真实尺寸、口播、持续运动或最终剪辑。完整对白和时长仍由分镜交接，图像分页不改变同场语义边界及30秒容量。
