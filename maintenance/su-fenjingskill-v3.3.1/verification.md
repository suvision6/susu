# su-fenjingskill 3.3.1 实施与验收记录

基线：3.3.0，提交`6a7311e16ded7058f28c9f99d47347eca35c6ef0`。本次新增独立目录`su-fenjingskill-v3.3.1/`，保留旧版。实施依据为本目录的[统一修复计划](repair-plan.md)；该计划保留升级前的历史状态，实际结果以本记录为准。

## 已落实

- Markdown作为可编辑分镜主稿：按镜头分块保存，镜头块顺序即播放顺序；原文和有效用户修正继续决定剧情。检查模式只需Node，不加载Excel依赖。正式流程不再要求JSON主稿。
- Excel从已保存主稿派生：六列、两张表，按内容分配列宽、计算行高。超长原文、描述、备注、场景、标题、设置和导演设计都可续行，文字逐字保留。
- 同一镜头只在首行计时，续行不增加切点。SUM合计秒数，COUNT统计逻辑镜头；暂存文件回读通过后才发布。已有目录可用，同名文件保护、替换前备份、主稿变更检测和派生失败恢复已实现。
- 创作指引补充来源到实际播放内容的反查、轻量续记、跨场声音与非线性顺序、梗概暂定设计、双语实际发言边界和已有授权继承。保留切／留／镜内重构自由及完整一镜估时，没有恢复镜数配额或逐镜证明字段。

运行包仍为9个文件。主入口SKILL.md为44行；新增的确定性逻辑集中在原导出器中。计划、回归脚本和样本放在包外，不增加每次导演任务的必读材料。

[regression.mjs](regression.mjs)完成16组断言检查，覆盖模板／CRLF、重复镜号与字段、未闭合围栏、非法整数、缺项、拒绝旧JSON输入、工作续记之后误追加镜头、特殊字符与较长围栏、A—B—A排列、既有目录、同名保护与备份、长文续行、列宽随内容变化、真实依赖阻断及局部编辑保留。

## 已知边界

1. 当前运行库2.8.52虽然提供冻结窗格调用，但未把窗格写入XLSX；也没有可验证的打印设置接口。需在Excel中设置冻结表头、打印重复行、纸张与分页。本轮没有把接口调用成功当作这些功能已保存。
2. 中文视觉检查使用Noto Sans SC的所需字形子集，未把字体打入Skill。部分emoji在当前渲染器中缺字形；“01”和纯空白文本在预览器中也可能被错误显示为数字，而独立读取的XLSX仍是原始文本。没有声称完成Mac／Windows Excel的实机验收。实际使用时优先采用阅读环境可用的完整中文字体。
3. 自适应发生在导出时；没有宏驱动的实时排版。手动改变列宽后，可在Excel重新自动调整行高，或按新阅读宽度重新派生。
4. 解析、文件回读和算术检查不判断剧情忠实或导演质量。本轮完成创作规则复核、跨场样稿通读和确定性交付验证，没有开展多轮独立Agent创作评测，不能据此承诺任意剧本均无需返工。

## 复现

在宿主允许的临时工作目录关联已有node_modules，使用宿主Node执行：

```text
node <repo>/maintenance/su-fenjingskill-v3.3.1/regression.mjs
python <repo>/maintenance/su-fenjingskill-v3.3.1/inspect_xlsx.py <生成的长文.xlsx> --expected-shots 2 --expected-seconds 216
```

回归会打印独立临时输出目录。可用环境变量`STORYBOARD_TEST_FONT`指定已有完整Noto Sans SC字体文件以完成中文测量与预览；不设置时测试仍可运行，但视觉结果须结合实际字体检查。字体子集取自[Fontsource中的Noto Sans SC](https://github.com/fontsource/font-files/tree/main/fonts/google/noto-sans-sc)，只用于本次检查环境。
