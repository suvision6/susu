# 专业验收样例

以下用于后续创作验收，不是本次已经运行的完整作品测试，也不是普通任务新增门禁。机械部分见test_master_compat.py。

| 编号 | 情境 | 应观察的结果 |
|---|---|---|
| F-T01 | 全新多人对峙 | 从信息与人物关系联合形成调度、摄影和切点，不预填正反打 |
| F-T02 | 长对白与话后反应 | 声音连续一次播放，听者覆盖不把后置反应提前 |
| F-T03 | 明确持续长镜／静候 | 保留连续观看收益，不为多样性虚构事件或切镜 |
| F-T04 | 只修改07镜路径 | 保留无关镜号、对白、摄影和时间，只检查真实受影响接点 |
| F-T05 | 更换题材和项目 | 不自动继承古装项目2—3秒反应基准；适用旧项目继续继承 |
| F-T06 | 边说边递物 | 按同步与先后计时，递到面前不等于接过 |
| F-T07 | 竖幅近景要求看桌下手 | 识别画框可见性冲突，在授权范围解决而非文字冒充已看见 |
| F-T08 | 旧稿与长正文导出 | 保持原模板解析、六列和两表、字面内容、未知值与旧文件 |
