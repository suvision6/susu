# 主稿保存、对白核对与派生

Python 3.10+。包内标准库后端完成主稿检查、JSON与XLSX，不需要账号、网络或必装第三方包。可选Pillow／fontconfig改善字宽估计，缺失仍用保守测量。不要寻找宿主隐藏模块或为这次升级更换表格后端。

## 命令与输出

```text
python3 <skill-root>/scripts/export_storyboard.py --input <主稿.md> --check
python3 <skill-root>/scripts/export_storyboard.py --input <主稿.md> --output-dir <新交付目录> --prefix <项目名>
```

`<skill-root>`是实际选择的完整Skill目录，不指向仓库中的无版本旧入口。Agent执行，用户不手写JSON。外部剧本由Agent理解后写模板，导出器不自动导演。

Markdown保留人工主稿，JSON／六列Excel同源；工作表为“导演分镜／导演设计”。六列仍是镜号、场景、原文、预计时长、完整声画、备注。场级条件随稿保存，原文、声音和导演依据不互相替代。未结构化附加内容保存在完整主稿快照，不冒称已理解。

只统一换行，围栏内字面、空格与段落保留；正文含围栏用更长外层围栏。不要更改模板解析标题。编号保留原文顺序及前导零，不必连续。未知时长使用“暂未确定”，JSON为null，不合计为0；已知小数保留。

## 保存与阅读

同名同内容JSON可回读，不同内容拒绝覆盖；已有Excel保留以保护人类批注，使用新前缀。单文件暂存、回读、发布，不称整组原子签发。Excel部分失败仍保留Markdown／JSON，不重写创作。相对来源链接相对原master，移动目录时保留相关主稿与来源。

整表宽度按实际内容分配，正文默认11pt；`--font`、`--font-size`、`--width-px`可调阅读条件。极长文本分为同镜续行，逐字重拼核对，时长只在首行；合计使用SUM与缓存值，未知数量另提示。等号开头等特殊原文作为文本，不成为公式。

冻结前3行、重复打印第3行表头、打印区域和横向多页设置由原生后端保留。字体替换会影响不同客户端显示，未经Mac Excel实看不宣称其验收。`--preview-dir`可选阅读预览，需可用渲染器；没预览不伪报已看，也不阻断已经回读的文件。

`--json-only`显式跳过Excel。返回0只表示本次结构／保存完成，1为输入／保存问题，2为JSON已保存但Excel失败；均不代表导演质量通过。

## 对白字面与局部预算检查

```text
python3 <skill-root>/scripts/review_dialogue.py --input <主稿.md> --cpm <中文每分钟字数> --wpm <英文WPM>
```

只用一种语言可省略另一项。`--source <采用原文.md>`指定独立来源；否则读取“来源依据”唯一文本围栏。`--output <核对.json>`保存检查，不是新主稿。

工具解析明确角色发言及正文播放锚点，按序拼接核对说话者、字面、次数、声位标记和本镜所选速度预算；不把普通引语或原文栏重复副本当声音。嵌套表演、引号内括注、数字缩写读法等有歧义时标待核，不猜原意。旧稿自然表达没被识别，只表示工具未核实，不证明全稿缺对白。

返回0为明确片段与所选数值检查完成，2为需回读／修正，1为读取／保存错误。没有有声对白不阻断导演工作。来源提取完整性、实际语速、同步动作、摄影可见性与语义仍由Agent回读；`semantic_review`继续为`not_performed_by_script`。

## 验收边界

结构、对白字面和载体同文可以确定性检查；表演、整场观看和实际时长不能靠脚本自动认证。不要让局部检查报告代替原文与完整采用正文。维护样例位于tests，不是普通任务的前置审批。
