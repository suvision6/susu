# 摄影表达：从机位到可见画框

首行使用 `【视角，景别，运镜】`，这是交付约定，不是全部摄影设计。三项之外的相机位置、朝向、前景、焦点与稳定质感进入自然正文。

## 设计顺序随任务变化

初次设计时，机位、人物调度、镜内观看和剪辑一起推敲；不要先固定所有反应切点再给每镜配设备。局部修改则保留已经采用且未受影响的覆盖，在其内修正摄影。用户重新设计整场的授权不等于撤销其明确保留的决定。

所选拍法说明实际关系：谁在前景、从哪侧看谁、相机相对谁的眼线、脸／手是否能读清、何处受挡。标签不同未必画面不同，同一标签也可能承担完全不同的观看。不要用改“平视”为“微仰”代替重新设计。

## 方法与可见结果

| 观看任务 | 可用方法 | 正文必须成立的结果 |
|---|---|---|
| 话语作用于对方 | 过肩、前后景、带关系单人 | 肩的归属、主体面孔、焦点及遮挡清楚；不读背身者正面表情 |
| 揭出人物或关系 | 前景遮挡、短横移／同侧弧移 | 起始遮挡、路线、显露对象与停止画框；不虚构前景人物 |
| 读亲疏、坐立或受压空间 | 侧面、适量俯仰、干净单人 | 相机高度相对主体与实际看到的身体范围；身份不自动决定高低 |
| 贴近关键落点 | 前推／拉出 | 从何种画框到何种画框，什么时候开始、停下；位移不冒称变焦 |
| 转向观看另一对象 | 摇摄 | 明确起止朝向；离开原主体后不再宣称能读其反应 |
| 跟随位移与交接 | 侧跟、后退伴随、弧跟 | 谁移动、相机在哪侧、距离与高度如何变化、何处落稳 |
| 稳定行进 | 斯坦尼康／稳定器式路径 | 先写跟随路径与启停质感，器材名不替代路线或自动形成长镜 |
| 保住反应阅读 | 固定或先动后稳 | 表演发生时可见，停住后结果可读；不让寻找人物占满镜长 |

前景与过肩是关系构图；俯仰是观察角度；推摇移跟是运动；斯坦尼康是稳定方式。可组合，但不能互相替代。AIGC中器材词描述预期影像特性，不保证模型听到名称就能实现。

## 一次运动要有起、行、落

自然写清起始画框、触发动作、连续路径和停止画框，不增加必填时间账本。通常一个主导运动足够，必要时配合保持主体的摇摄，不堆推移环绕变焦表示丰富。

假设来源已有递匣：相机从持匣者斜前方同侧伴随，接近受领人时减速成两人侧向关系；持有与接触按真实时点变化。不能仅写“跟拍木匣”，也不能为了镜头运动新增人物走动。

人物原地转头不意味着镜头必须顺视线摇走。需要读眼神时保住面孔；明确需要揭示视线目标时才离开。运动中的表情已经可读则计入阅读，不机械叠加一份运动后停留。

## 专业词与身体范围

视角可用平视、俯拍、仰拍、顶拍及有依据的连续变化；景别可用远景、全景、中全景、中景、中近景、近景、特写、大特写；运镜可用固定、前后移、横移、摇、跟、弧移、升降或变焦。词表不是封闭白名单，其他方法须说明其实际影像。

过肩、双人、负空间、框中框不是景别；长焦不是视角，竖屏不是运镜，“切到”不是连续运动。中景通常能纳入腰部动作，近景不能凭文字声称看见画外双手；以实际裁切与本镜任务为准，不硬编码唯一景别边界。

原位摇摄改变朝向，升降改变相机高度，前后移改变位置，变焦改变焦距，调焦改变清晰平面。坐姿起身时，原位上摇可能从平视变仰视；同步升高相机可维持平视，不能只改标签而让路径不成立。新切机位各自成立，不要求把搬相机的过程拍出来。

## 画幅先于构图

9:16人物冲突可优先考虑中近景／近景，通过过肩和纵深组织多人；必要全景与完整动作仍保留。横向运动可能离开窄画框，不能自动提速。16:9／1.85:1兼顾横向关系与纵深；2.0—2.39:1可利用距离、负空间和层次，不强迫大全景；4:3可集中身体与纵深，不自动等于文艺慢节奏。多画幅明确适用段落，不把后期裁切假称导演变幅。

固定与运动按内容形成对比，不以比例验收。受压空间不是擅加高台、让人物瞬移的理由；画左画右从当前相机投影推导，不绑定人物身份。

## 三项实际复核

所写表演能否被本画框看见；相机路线与固定物／人物是否相容；相邻镜的方向、视线、声位与动作阶段能否接上。只修表达时不换用户指定机位，条件确实矛盾则定位局部选择。三要素齐全不等于这三项成立。
