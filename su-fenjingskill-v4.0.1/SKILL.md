# 导演分镜

版本见 [VERSION](VERSION)。核心任务是把剧本导演成声画、表演与空间成立的镜头；文件派生只服务交付。

## 1. 读来源，确定本次工作的范围

读取完整来源或明确片段、相关上下文与有效修正，分清原文、用户采用稿和Agent旧建议。只有旧产物时说明范围，不冒称核对了未提供的原文。原文与对白字面不改；必要且不改剧情的机位、调度和可逆表演可在授权内设计，不能把潜台词推断或临时场地当事实。梗概展开标明暂定。

初次设计时，人物调度、声音连续性、镜内观看和剪辑切点共同推敲，不预先冻结正反打。局部修改时，定位被授权改变的语句、摄影、时间或行为，只扩展到真实受影响的接点。明确重新设计整场时，不把旧Agent自选机位当用户锁定条件；实际已采用决定按授权范围保留。此判断不增加字段、状态机或人工Gate。

在原“项目条件”中写明载体、题材、实际对白语言与说明语言、画幅、计划语速及停顿口径、反应阅读节奏、片长是否硬要求。已有条件沿用；新项目按实际内容作计划假设，不自动套上一项目。生成画面默认无后期字幕，剧情实物文字与声音仍保留。

## 2. 先确定整场怎样看，再联合形成镜头

读 [导演方法](references/directing.md)。从人物行动、对象、策略、刺激与关系理解节拍，不按台词行、标点或动词数拆镜。在现有“表演节拍与观看／场景、摄影与声音”中，用短段说明本场具体的信息获取和观看方式；没有转折的等待不强造转折。只保存采用方案，不交逐镜收益证明或多套备选问卷。

根据戏比较同框、镜内调度与剪辑对比。长发言可以连续跨镜，看听者不等于新增反应；原文明确在话后发生的动作仍留在话后。关键个体反应与实际可见群体反响各自落实，不能互相替代。长镜、固定观察和静默均可成立，不设镜数、角度或运镜配额。

按 [摄影表达](references/camera-language.md)把所选观看变成真实画框：相机相对谁、从哪一侧看、前景属于谁、何处可读或被挡、运动如何触发并停住。一个镜号对应连续画面；真实剪切另列镜号，声桥不断也不能把正反打写成一镜。

## 3. 将声音、表演与时间写在同一过程里

读 [对白与时间](references/dialogue-and-time.md)。只数实际播放的台词，不按描述字数估时；动作、运镜与环境变化按真实先后和重叠理解，静态服饰不逐项加秒。先估完整发言，再安排观看切点；每镜实际片段也要说得完，不能借邻镜余量或改速率圆旧数字。

执行正文就地嵌入 `角色（声位）：“逐字片段”`，保留原语、说话者、顺序和次数。原文栏、备注或“说完整句”不能代替播放文本；OS依上下文区分内心、旁白与现场画外。无声口形、真实道具文字另写用途。

反应必须在可读画框中发生并让结果被理解。具体秒数属于本项目条件，不是全体题材的统一下限；已经明确采用的古装人物戏2—3秒基准继续只在该项目生效。中途听者画面占既有声音时间，话后真正停下的反应才另占时间。不给每镜统一安全余量。

## 4. 写主稿，连续复核，局部解决问题

用 [原主稿模板](templates/storyboard.md)保留六项：镜号、场景、原文、预计时长、完整声画、备注。完整声画以 `【视角，景别，运镜】` 开头，自然写实际机位、可见动作、播放对白和结束状态。场级人物外观在首次适当画面落实，后镜继承，不逐镜重抄。

按 [中文等义表达](references/meaning-and-expression.md)先从来源检查遗漏，再只读执行正文复述成片，查是否擅加接受、拒绝、位移、情绪或结果。整场再看信息、关系与节奏是否推进，而不以摄影标签种类验收。局部未定动作在备注定位，正文不能先选答案；无关部分继续完成。

最后核对相关空间、视线、轴侧、持物和声音接点。局部修句保留有效摄影和时间；实质改变行为或时点才重估受影响范围。图像发现的问题可以反馈，但不让下游悄悄重新导演。

## 5. 保存与交接

按 [交付说明](references/delivery.md)保存Markdown，再派生JSON与六列Excel；保留“导演分镜／导演设计”两表。只检查结构的脚本不认证导演质量、实际口播或空间。派生失败保留主稿，不重写整场。

不生成视频Prompt、不配置模型、不为九格凑镜、不按30秒装箱。image9的过程图不增镜号，Prompt按采用分镜一源镜一Cut组织提交。没有这些下游环节，导演分镜也应独立完成。
