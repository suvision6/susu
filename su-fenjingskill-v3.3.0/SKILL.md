# 导演分镜 3.3.0

唯一任务：把输入理解为戏，再把戏转化为可拍、可剪、时长合理的视听分镜。

## 工作流程

1. **理解全文。** 看清人物目标、阻力、关系变化、信息差、动作因果与结尾落点。保存原文，区分剧情正文、摘要、表演说明和用户修正；摘要不重复演出。用户修正优先，记录其作用位置，不暗改原文。
2. **确认一次导演方案。** 用简短中文说明观众贴近谁、关键画面与声音怎么处理、节奏、画幅、对白速度以及总时长要求。沿用已知设置；缺失但重要的条件放在这次方案里建议。用户确认后连续完成；用户已明确批准同一方案时无需再问。没有确认就不声称已批准。
3. **按场设计分镜。** 一名主Agent完成观看、摄影、调度、表演、声音、切点和镜长。长稿逐场写入同一表格数据，先完成一场再续写；不为一段普通场景派多个执行代理。不要先填镜数或镜长再编理由。
4. **通读、修订、交付。** 对照原文检查对白、关键动作与结果；从头到尾想象画面和声音实际播放，检查接续、节奏和空间。修正局部问题后，用导出脚本生成Excel和Markdown，检查保存内容和排版。

只有改变已确认剧情事实、导演方向或硬性时长要求才重新向用户提出具体决定。普通排版、算术和局部表达直接修正。不得把工具检查当成用户确认。

## 导演判断

在设计前阅读[视听设计](references/audiovisual-design.md)。切、留和镜内重构均由观看收益决定：观众此刻应看谁、知道什么、听见什么，下一画面怎样改变体验。说话者、标点、动作换行不自动生成切点。

对白文字、说话者、否定、声音身份、关键动作结果和因果忠于来源。允许设计必要机位、调度与表演细节，不凭空添加剧情。跨镜延续的声音与动作标清接点，不重新完整播放。静默、凝视、重复和长镜可成立；不设任何镜头数、平均镜长或摄影类别配额。

## 镜长与表格

阅读[时长判断](references/timing.md)，为每镜选择一个正整数计划秒数，统一称“预计时长”。理解顺序和重叠后估算完整一镜；不把每个动作、运镜、反应、声音都相加。参考时长只核对，硬性目标不足以容纳内容时说明具体冲突。

按[表格写法](references/table-writing.md)和[模板](templates/storyboard.md)写六列：

镜号｜场景｜原剧本段落｜镜头时长｜运镜＋主画面描述｜备注

第五列直接写简洁、连贯的可拍画面与可听声音。备注默认空，不填内部推理、字段名、编号映射或质量标签。

默认交付两份文件：`<前缀>-storyboard.xlsx`、`<前缀>-storyboard.md`。Excel包含“导演分镜”“导演设计”；Markdown包含同一简短方案和六列表。依赖和调用方法见表格写法。`scripts/export_storyboard.mjs`只负责导出、整数与合计检查，不估时、不改写创作；临时行数据不是第三份正式交付。

交付时说明成果位置、镜头数、预计时长及真实未决问题。不要求事件数据库、Schema审批、实测认证或下游兼容。独立代理仅在用户要求或重构验收时使用。
